# Phantom Drive · 工创小车

> 华南理工大学 工程创新训练中心 · 工程训练分散项目
> 「重走古丝路 · 自动循迹避障小车」

## 项目速览

- **任务**：全自动循迹（6200×2000mm 赛道，4 赛段）+ 动态避障（4 个随机摆位障碍物）+ 终点精停
- **平台**：STM32F103C8T6 · 亚博智能八路灰度 · TB6612 · 三轮构型
- **时间**：第 4 周启动 · 预测第 9 周比赛 · 内部冻结死线第 8 周末
- **成员**：李沛阳（组长）、王政淋、熊雅琦、李昕程、毕烨恺

## 协作规范（简短版）

1. `main` 分支保持"能编译 / 能跑"；各自任务开分支：`feat/*`、`hw/*`、`mech/*`
2. **固定顺序：拉取 → 放入 → 提交** —— 动手前双击「`拉取.bat`」同步云端，干完活双击「`提交.bat`」上传；提交信息格式 `类型: 内容`（如 `feat: 串口遥测协议`）
3. 大文件与编译产物不入库（见 `.gitignore`）；发票扫描件等敏感文件不要进仓库
