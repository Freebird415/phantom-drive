# Phantom Drive · 工创小车

> 华南理工大学 工程创新训练中心 · 工程训练分散项目
> 「重走古丝路 · 自动循迹避障小车」

## 项目速览

- **任务**：全自动循迹（6200×2000mm 赛道，4 赛段）+ 动态避障（4 个随机摆位障碍物）+ 终点精停
- **平台**：STM32F103C8T6 · 感为八路灰度（主，I2C1）／亚博 YB-MUX04（备）· HC-SR04 超声波 ×2 · TB6612 · 三轮构型
- **时间**：9/21 项目启动 · 预测比赛周 10/26~11/1 · 内部全功能冻结 **10/25**（节点已小幅前移，见 `计划和任务/任务清单.md`）
- **当前（10/10 傍晚）**：**PCB v2.1 已装车、电器验收正常**；**A01 无障碍全程试跑通过**（2126 帧，用户确认循迹部分完成；保守基线 **22% / 不命令反转**）；无线日志工具链（网页界面 + 监测模式）就绪；
  ⚠️ **A02 避障未闭环**：20cm 试跑第一障碍绕开、第二障碍弯道回线失败；**v4 两趟实跑 gz 恒 0 ⇒ 持续打舵、约半圈后外廓保护**（当前最高优先，`决策登记` O-10）；
  ✅ BLE 识别故障已闭环（原核心板 3V3 网络故障 → 换板；E-32）；**放弃 OLED**（E-33）；**电气文档已按实物原理图逐针校正**（E-34）；⚠️ 15° 探头新几何**待标测**
- **成员**：李沛阳（组长）、王政淋、熊雅琦、李昕程、毕烨恺

## 协作规范（简短版）

1. `main` 分支保持"能编译 / 能跑"；各自任务开分支：`feat/*`、`hw/*`、`mech/*`
2. **固定顺序：拉取 → 放入 → 提交** —— 动手前双击「`拉取.bat`」同步云端，干完活双击「`提交.bat`」上传；提交信息格式 `类型: 内容`（如 `feat: 串口遥测协议`）
3. **动手前先扫 `项目记录/决策登记.md`**（已拍板/已冻结事项），别把已定的事重新推导一遍
4. 开发调试用根目录「`工具箱.bat`」或 VS Code（打开 `firmware/`，装 PlatformIO IDE 插件）
5. **AI 留言（`留言板.md`，根 / 各工作区）**：开工先读；有交接/意图/提醒就写一条（≤3 行、署名、**单独提交**、只改自己的）；提交后 AI 会把留言贴给你过目，有异议就让它撤回
6. 大文件与编译产物不入库（见 `.gitignore`）；发票扫描件等敏感文件不要进仓库
7. **`commit` / `push` 必须先经用户（组长）确认**（留言板留言是唯一例外，见 `AGENTS.md` 硬规则 2）
