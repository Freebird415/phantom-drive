# 设计文件 —— 李昕程把要给大家用的文件传到这里

> 谁用：王政淋画 PCB 要看你的尺寸；M02 加工要拿图纸；M01 要交的东西也在这里。
> 导出件与**建模源文件**都传（文件都不大）——源文件是答辩要展示的「自行设计」证据。

## 要传哪些

| # | 文件 | 说明 |
|---|---|---|
| 1 | `整车.step` | 整车装配体（能看出全部零件和位置） |
| 2 | 加工件 `*.stl` / `*.dxf` | 3D 打印件给 `.stl`；激光切割件给 `.dxf` |
| 3 | `*.pdf` 工程图 | 至少一张整车图 + 每件加工图，带上主要尺寸 |
| 4 | 尺寸核对表 | 长×宽×高（**含轮子、传感器、插头等突出件**）→ 红线 ≤250×200×200mm |
| 5 | 关键孔位 | 电机、万向轮、PCB 铜柱、电池位置的孔（写清 X / Y / 孔径，单位 mm） |
| 6 | **建模源文件** | SolidWorks 工程（`.SLDPRT` / `.SLDASM` 等）——答辩要证明「自行设计」；文件不大，直接传仓库 |

第 4、5 项可以直接写成一份 `尺寸与孔位.md` 放在本目录，也可以标在工程图上——**能让人看懂就行**，不用写很正式。
