# mech —— 机械设计与加工

| 位置 | 内容 |
|---|---|
| `设计文件/` | 整车 `定版-装配体.STEP`、加工件 `定版-底板3D打印件.STL` / `定版-底板.DXF`、建模源文件 `定版-方形底板.SLDPRT` |

## 红线

| 项 | 要求 |
|---|---|
| 尺寸 | 整车 ≤ 250×200×200mm（长×宽×高），超标每轮扣 10% |
| 自制 | 车架必须自制（主结构自己设计 + 中心设备加工 + 全程留证），买现成一票否决 |
| 构型 | 三轮：双 JGB37-520 减速电机（12V 333RPM）+ 1 万向轮，差速转向 |
| 单电源 | 布局要给电池与降压模块留位置 |

定版车架 = `设计文件/` 中与成车一致的版本（3D 打印件 + 激光切割铝板）。
