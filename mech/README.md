# mech —— 机械设计与加工

机械设计与加工：模型与图纸的导出件、加工装配证据。
- 相关任务：M01 结构设计与建模 · M02 加工与装配
- 主要使用者：李昕程（M01 · M02）；熊雅琦配合装配与拍照（S02）

## 这里有什么

| 位置 | 内容 | 谁放 |
|---|---|---|
| `设计文件/` | 整车 STEP、加工件 STL/DXF、工程图 PDF、尺寸与孔位（**要传哪些看该目录 README**） | 李昕程 |

| `车架与PCB对接约定.md` | 板子多大、装哪、孔在哪、线从哪出——**王政淋和李昕程一起填** | 两人共同 |

## 要求（红线）

| 要求 | 依据 / 说明 |
|---|---|
| **整车尺寸 ≤ 250×200×200mm（长×宽×高）** | 比赛规则原文；超标每轮扣 10%。按上限预留余量 |
| **车架必须自制，主结构自己设计** | 可用 3D 打印、激光加工、数控加工、木工；**非自制不允许参赛**（一票否决） |
| **必须用中心设备加工并留证据** | 加工过程照片/视频 + 设计图源文件，答辩时要展示 |
| 标准件可用 | 螺丝、轴承、合页等标准件允许使用，但**主结构必须自制** |
| 三轮构型 | 双 JGB37-520 减速电机（12V 333RPM）+ 1 个万向轮，差速转向 |
| 单电源 | 车上只能装一块电源（12V 锂电池）——布局要给电池、降压模块留位置 |
| 全自动 | 车上不得有遥控通道，比赛禁遥控 |
