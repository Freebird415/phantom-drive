# mech —— 机械设计与加工

机械设计与加工：SolidWorks 加工图导出（PDF/STEP/STL）、孔位坐标表、装配记录、加工证据（照片/视频）。

- 相关任务：M01 结构设计与建模 · M02 加工与装配
- 主要使用者：李昕程（M01 · M02）；熊雅琦配合装配与拍照（S02）

## 要求（红线）

| 要求 | 依据 / 说明 |
|---|---|
| **整车尺寸 ≤ 250×200×200mm（长×宽×高）** | 比赛规则原文；超标每轮扣 10% 成绩。建模时按上限预留余量 |
| **车架必须自制，主结构自己设计** | 可用 3D 打印、激光加工、数控加工、木工；**非自制不允许参赛**（一票否决） |
| **必须用中心设备加工并留证据** | 留加工过程照片/视频（如激光切割机、3D 打印机旁操作的照片）＋设计图源文件，答辩时要展示（自制性评分项） |
| 标准件可用 | 螺丝、轴承、合页等标准件允许使用，但**主结构必须自制** |
| 三轮构型 | 双 JGB37-520 减速电机（12V 333RPM）+ 1 个万向轮，差速转向 |
| 单电源 | 车上只能装一块电源（12V 锂电池）——布局要给电池、降压模块留位置 |
| 全自动 | 车上不得有遥控通道，比赛禁遥控 |

## 建模草案的标准（第 3 周末）

既要“看得见”，也要“量得出”。共 5 项交付：

| # | 交付 | 验收标准 |
|---|---|---|
| 1 | **整车可装配 3D 模型** | 底盘/车架 + 2 电机 + 车轮 + 万向轮 + 电池 + 核心板（PCB 区）都就位，主要件有安装面与定位 |
| 2 | **整车尺寸核对表** | 长×宽×高实际值（**含所有突出件**：轮、传感器、插头、铜柱、蓝牙）+ 上限 + 余量；建议控在 245×195×195 以内 |
| 3 | **导出件入仓库** | `整车.step`（装配体）、加工件 `*.stl`（3D 打印）/ `*.dxf`（激光切割）、`*.pdf` 工程图（**带总尺寸与关键尺寸**）|
| 4 | **孔位坐标表** | 以统一基准点为原点，列出每个孔的 X / Y / 孔径 / 用途（mm 表格）|
| 5 | **源文件放网盘** | `.sldprt/.sldasm/.slddrw` 体积大**不进仓库**，放网盘并在本文件记链接（答辩的“自制 + 中心设备”证据要用）|

> 《安装接口契约》= 给王政淋的 **PCB 尺寸依据**（板能做多大、孔打在哪、接口留哪侧）→ 用 `安装接口契约.md` 模板填，六块内容填完给他确认。
