# 加工证据 —— 自制车架的证据都放这里（答辩要展示）

> 为什么重要：规则要求车架**必须自己设计 + 用中心设备加工**，答辩时要拿出设计和加工过程。
> 没有证据 = 说不清是不是自制 = 一票否决风险，所以从第一次加工开始就要拍。

## 放什么

| 类型 | 例子 |
|---|---|
| 加工过程照片 | 在 3D 打印机 / 激光切割机 / 钻床旁操作的照片（能看出是谁、在哪台设备） |
| 过程视频 | 切割、打印、装配的短视频（手机随手拍即可） |
| 装配记录 | 关键步骤照片、尺寸复测记录、遇到的问题 |
| 文件 | 导出件本身在 `../设计文件/`，不用在这里重复放 |

## 怎么拍（省事版）

1. 开工、中途、完工各拍一张，能看到**设备和半成品**同框
2. 文件名写清日期和内容，如 `1010-激光切割底板-01.jpg`
3. 拍完直接放进本目录提交上来（不用整理得很好看，能认出来就行）
