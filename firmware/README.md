## 超声波（HC-SR04 ×2）

| 项 | 接线 |
|---|---|
| 左模块 | VCC→**5V**，GND→GND，Trig→**PA4**，Echo→**PA5** |
| 右模块 | VCC→**5V**，GND→GND，Trig→**PA1**，Echo→**PB5** |

| 注意 | 说明 |
|---|---|
| **VCC 必须 5V** | 只插 ST-Link 时蓝板 5V 脚**没有输出** —— 必须再接 micro-USB（或另一路 5V）并共地 |
| **Echo 是 5V 输出** | 正式版串 2k/3.3k 分压（5V→3.11V）；面包板可先直连（PA5/PB5 是 **FT 5V 容忍**脚），但绝不能接到非 FT 脚 |
| **两颗不能同时触发** | 固件已做成“每 100ms 一颗、左右轮流” |
| 已知取舍 | 等回波是阻塞式，最坏一次阻塞 30ms → `$T` 的 100Hz 会出现时间戳抖动（帧不丢，成簇输出）；正式版改非阻塞状态机 |

### 实测结论（2026-09-23 面包板 bring-up）

| 项 | 实测 |
|---|---|
| 机械约束 | 探头**距反射面 ≥ 25~30cm**：≥20cm 时全部 100%；**< 20cm 掉到 37~58%**（振铃盲区，与代码无关） |
| 角度约束 | 波束角仅 ~15°，**歪 10° 就整个打偏**（手持时一颗读 206mm、另一颗读 575mm；转正后立刻变成 322/332mm） |
| 最终验收 | 两颗中位 **322 / 332mm**，右侧连续三轮 **100%**，左侧 73%（模块个体差异，待对调模块定性） |
| 节拍 | 驱动层强制（同一颗 60ms 最小间隔、**失败后 600ms 恢复期**）；主循环默认 **250ms** 一颗。曾试 100ms：左侧掉到 42%（恢复期把节拍拦下） |
| 注意 | **PA5 与 PB5 共用 EXTI5** —— 以后改中断/输入捕获方式时必须换脚 |

看数据：`$U,<ms>,<l_mm>,<r_mm>`，单位 mm；**−1 = 无回波，−2 = 回波异常**。

### bring-up 自检命令（对着串口调，不用反复重烧）

| 命令 | 作用 |
|---|---|
| `US` | 立即测一轮（左→隔 70ms→右），并打出一行人可读的 `US[L]/US[R]` 调试行 |
| `US <id> <n>` | 只测某一颗 n 次（**id：0 = 左，1 = 右**）：`US 0 5` = 左测 5 次，`US 1 10` = 右测 10 次 |
| `AUTO 0/1/2/3` | 主循环的自动测距：`0`关 / `1`左右轮流（默认）/ `2`只左 / `3`只右（隔离实验用） |
| `PING` / `GET` / `SET <名> <值>` | 连通性 / 读参数 / 改参数 |

> 调试时先 `AUTO 0`，让 `US` 命令独占节拍 —— 两个源头同时打会让读数失去意义。

## 目录规则（改目录前先看这里）

```
firmware/
├── platformio.ini          PlatformIO 工程配置（只放构建相关）
├── README.md               本文件：要求 / 接线 / 目录规则 / 怎么用
└── src/                    ★ 只有会编进固件的源码放这里（PlatformIO 递归编译）
    ├── main.c              唯一的 main：初始化 + 主循环（只写“流程”，不写器件细节）
    ├── bsp/                板级资源（芯片外设：时钟 / 计时 / 串口 / 指示灯…）  bsp_xxx.{c,h}
    ├── drv/                器件驱动（车上每个模块一个文件）                drv_xxx.{c,h}
    └── app/                应用层（遥测帧、参数、命令解析；以后放 PID/状态机）app_xxx.{c,h}
```

| 规则 | 说明 |
|---|---|
| **分层只看依赖方向** | `app → drv → bsp`，**不准反向**（drv 不 include app；bsp 不 include drv） |
| **一个器件一个文件** | 新增模块 → 在 `drv/` 加一对 `drv_xxx.{c,h}`，在 `main.c` 初始化，在 `app/app_telemetry.c` 里注册一个自检命令 |
| **每个驱动带 bring-up 自检** | 必须提供 `Xxx_Init()` 与 `Xxx_PrintDebug()`；命令名用大写缩写（已用：`US`、`AUTO`） |
| **不在 src/ 放非源码** | 日志 / 截图 / 实验数据 / 说明都放外面（日志在仓库根 `logs/`，已 gitignore） |
| **不改分层** | 要新增/移动/重命名目录，先改本节并说明理由；目录规则本身是契约 |
| **提交前必须能编** | `pio run -d firmware` 零 warning；上车测试用 `tools/run.py` 自动落盘到 `logs/` |

> 为什么把驱动单独拆出来：P02（驱动接口初版 9/30）要交给 A01/A02 一份**冻结的接口**，
> 单独放在 `drv/` 下才能单独评审、单独冻结；混在 main.c 里既没法评审也没法并行开发。

## 怎么用（在仓库根目录执行）

```bash
python tools/run.py --note "第一次测试" --seconds 20        # 编译+烧录+采集+出图
python tools/run.py --note "..." --seconds 20 --no-flash   # 只采集
python tools/run.py --note "调超声波" --seconds 15 --raw     # 只看原始串口（排查接线用）
pio run -d firmware -t upload                              # 只编译+烧录
cd firmware && pio device monitor                          # 直接看串口（Ctrl+C 退出）
```

## 硬件接线

| 用途 | 接线 |
|---|---|
| 烧录（ST-Link） | SWDIO→PA13，SWCLK→PA14，GND→GND，3V3→3V3 |
| 串口（USB-TTL） | TTL TXD→**PA10**（RX），TTL RXD→**PA9**（TX），GND→GND（TTL 的电源脚不要接） |
| 超声波 ×2 | 见上方《超声波》表（左 PA4/PA5，右 PA1/PB5；VCC 必须 5V） |

时钟：HSI 8 MHz → PLL → 64 MHz（不依赖外部晶振，开发板差异不影响）
