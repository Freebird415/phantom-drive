## 一、分层规则（写代码前必读）

```
app/  （应用层：遥测帧、参数、命令解析、将来的算法）
  ↓  只能往下调
drv/  （器件驱动：一个器件一对 drv_xxx.{c,h}）
  ↓
bsp/  （板级：时钟 / µs 计时 / 串口 / 指示灯）
```

**规则**（详见 `firmware/README.md`）：

| # | 规则 |
|---|---|
| 1 | **依赖方向只允许 app → drv → bsp**，不许反向、不许跨层直接摸寄存器 |
| 2 | 新增器件 = `drv/` 加**一对** `drv_xxx.{c,h}` + 在 `app_telemetry.c` 注册一条**大写缩写**自检命令 |
| 3 | `src/` 只放**会编进固件**的源码；新函数先加 `drv` 层，不要在 `main.c` 里堆逻辑 |
| 4 | 要改分层 → **先改 `firmware/README.md`** 再改代码 |
| 5 | 编译必须**零 warning** |

**算法写在哪**：A01/A02 的代码请新建 `app/app_trace.c` / `app/app_avoid.c`（或直接在 `main()` 主循环里调），**只调 `drv_*` 的函数**，不要直接操作 GPIO/TIM/I2C。

### 3.2 超声波 · `drv/drv_ultrasonic.h`

| 接口 | 说明 |
|---|---|
| `void Us_Init(void)` | 初始化两个 Trig 脚（PA4 左 / PA1 右）|
| `int32_t Us_Read(UsId id)` | **测一次**：返回 **mm（正数）** 或**负状态码**（见下表），并更新内部记录 |
| `UsDev *Us_Get(UsId id)` | 取最近一次结果的结构体（`mm` / `width_us` / `stamp_ms` / `last_ok`）|
| `void Us_PrintDebug(UsId id)` | 打一行人可读信息（bring-up 用）|

`UsId`：`US_L = 0`（左）/ `US_R = 1`（右）

**状态码（返回值可能是负的，判避障前必须先判这个）**

| 值 | 名字 | 含义 |
|---|---|---|
| 0 | `US_OK` | 测到了（此时返回值 >0，单位 mm）|
| −1 | `US_NO_RISE` | 没等到上升沿：没回波 / 没供电 / 接错脚 |
| −2 | `US_TOO_LONG` | 高电平 >30ms：超量程（模块没回波时会输出约 200ms 高）|
| −3 | `US_BUSY` | 触发前 Echo 还是高的：上一发没结束 |
| −4 | `US_TOO_SHORT` | 高电平 <100µs：不合理窄脉冲 |
| −5 | `US_OUT_RANGE` | 换算后 <20mm 或 >4000mm |
| −6 | `US_TOO_SOON` | 距上次触发不足 `US_MIN_GAP_MS`（60ms），被驱动拦下（**不算故障**）|

**⚠️ 硬约束（不遵守会拿到错数据）**

| # | 约束 | 依据 |
|---|---|---|
| 1 | 模块 VCC 必须 **5V** | 3.3V 带不动 |
| 2 | **两颗不能同时触发**（会收到对方回波）→ 调用方轮流 + 间隔 | 面板实测 |
| 3 | 同一颗两次触发间隔 ≥ **60ms**（`US_MIN_GAP_MS`）；**失败后要 600ms 恢复期**（`US_RECOVER_MS`）| 实测会"假 −2"/锁死 |
| 4 | 探头**距反射面 ≥ 25~30cm**；两颗必须**平行正对**（波束角仅 ~15°）| 实测 <20cm 成功率掉到 37~58% |
| 5 | Echo 是 5V 输出 → 正式版串 **2k/3.3k 分压** | PA5/PB5 是 FT 脚，面包板可直连 |

**主循环节奏**：`main.c` 里默认 **250ms 一颗**（左右各 2Hz，实测 100%）。`AUTO 0` 可关掉自动测量，让 `US` 命令独占节拍。

> ⚠️ **PA5 与 PB5 共用 EXTI5** —— 现在用**阻塞轮询**所以没事；**若以后改成中断/输入捕获，必须把其中一颗换脚**（`决策 E-18`）。

### 3.3 八路灰度 · `drv/drv_grayscale.h`

| 接口 | 说明 |
|---|---|
| `void Gr_Init(void)` | I2C1 初始化（PB8=SCL / PB9=SDA，**重映射**，100kHz）|
| `uint8_t Gr_Ping(void)` | 返回 **1 = 收到 0x66**，设备在线 |
| `uint8_t Gr_ReadDigital(void)` | 1 字节：**bit0 = 第 1 路 … bit7 = 第 8 路**（手册：LED 亮 = 1）|
| `uint8_t Gr_ReadAnalog(uint8_t out[8])` | 读 8 路模拟量（0~255）|
| `void Gr_Scan(void)` | 扫 I2C 总线有哪些地址应答（**排查接线/上拉/地址最有效**）|
| `void Gr_PrintDebug(void)` | 一行可读：ping + 数字量 + 8 路模拟量 |

**⚠️ 硬约束**

| # | 约束 | 依据 |
|---|---|---|
| 1 | **I2C1 上拉必须是 5V**（不是 3.3V）| 感为手册：外置上拉源不得低于供电的 72%（=3.6V）|
| 2 | 一条总线**只允许一处上拉源**（插了模块板载跳帽就别再并 3.3V 上拉）| 防对顶/漏电 |
| 3 | 这条总线**绝不能**挂 3.3V 器件（OLED/MPU 走 I2C2）| 5V 会打坏 |
| 4 | 安装高度按手册 **~20mm**；**校准后不得改高度**；**装车后与比赛现场必须重校** | `决策 E-19` |
| 5 | 7bit 地址 = **0x4C**（AD1/AD0 都不装跳线）；两个都装 = 0x4F | 手册 + 实测 |

**判定约定（A01 会用）**：实测白场上 8 路模拟量摆幅 18~134、`dir` 分档正确，**黑线 = 1**。
→ **装到实车、换到真实赛道后必须重新校准一次**（光照/标高/材质变了 `dir` 会变）。

> 备用方案：亚博 YB-MUX04 占**另一个独立 16P 座**（`决策 E-02`），当前未启用。

### 3.4 OLED · `drv/drv_oled.h`

| 接口 | 说明 |
|---|---|
| `void Ol_Init(void)` | I2C2 初始化（PB10/PB11）|
| `I2C_HandleTypeDef *Ol_Bus(void)` | **暴露 I2C2 句柄**（MPU6050 共用同一条总线）|
| `void Ol_Present(void)` | 探测并打印地址（0x3C/0x3D）|
| `void Ol_PrintDebug(void)` | 初始化 + 画棋盘测试图案 |
| `void Ol_TextTest(void)` | 中英文混排测试页 + 报告缺失字符 |
| `void Ol_FbClear(void)` | 清帧缓冲 |
| `void Ol_FbFlush(void)` | 把帧缓冲刷到屏（**画完必须调这个**）|
| `int Ol_Text(int x, int page, const char *utf8)` | 在 `x` 列 / `page` 行写 UTF-8 串；**返回缺失字符个数**（−1 = 整串没画）|

**⚠️ 硬约束**：**VCC 必须 3.3V**（板载 4.7k 上拉拉到 VCC；接 5V 会把整条 I2C2 拉高 → 打坏 MPU6050）；**绝不能挂 I2C1**。

**字库是子集生成的**：ASCII 6×8（0x20~0x7E）+ 汉字 16×16（**只有 `tools/生成字库.py` 的 `CN_CHARS` 里列的那些**）。
要显示新汉字 → **改字表 → 重跑脚本 → 重新编译**；字库里没有的字会画"空心方框"并在串口报警。

OLED 尺寸：`OLED_W = 128`、`OLED_H = 64`，共 8 页（`page` 0~7），汉字占 **2 页**（16 像素高）。

## 四、给 A01/A02 的调用骨架

以下只用了**上表已存在的函数**，可以照抄思路（不是可直接运行的完整算法）。

### A01 · 循迹（读灰度 → 算误差 → 控电机）

```c
/* 建议新文件 app/app_trace.c，并在 main() 主循环里调用 */
#include "drv/drv_grayscale.h"
#include "drv/drv_motor.h"
#include "drv/drv_encoder.h"
#include "app/app_telemetry.h"

void Trace_Step(void)
{
    uint8_t d = Gr_ReadDigital();          /* bit0=第1路 … bit7=第8路（黑=1）*/

    /* ① 加权求偏差：把 8 位转成 −3.5 ~ +3.5 的位置误差 */
    float sum = 0.0f, wsum = 0.0f;
    for (int i = 0; i < 8; i++) {
        if (d & (1u << i)) { float w = (float)i - 3.5f; sum += w; wsum += 1.0f; }
    }
    float err = (wsum > 0.0f) ? (sum / wsum) : 0.0f;   /* 全白 = 丢线，另行处理 */

    /* ② PID（参数在线可调：SET kp 8）*/
    Params *p = Tlm_Params();
    int base  = p->base_speed;
    int steer = (int)(p->kp * err);                    /* 先只用 P，跑起来再加 I/D */
    Mo_Set(base + steer, base - steer);                /* 左快右慢 → 往左修 */

    /* ③ 上报（把 main.c 里那段模拟数据换成这一行）*/
    int s[8]; for (int i = 0; i < 8; i++) { s[i] = (d >> i) & 1u; }
    Tlm_SendT(HAL_GetTick(), s, err, base + steer, base - steer, 1);
}
```

**A01 注意**：`En_Count()` 目前**只有计数没有速度**，要做速度环得自己在两次调用间做差分（或先只用位置环）。

### A02 · 避障（读超声波 → 判状态 → 决策）

```c
/* 建议新文件 app/app_avoid.c */
#include "drv/drv_ultrasonic.h"
#include "drv/drv_motor.h"

/* 把"读数 + 状态码"统一成一个距离，方便判断 */
static float Us_DistanceCm(UsId id, float fallback_cm)
{
    int32_t v = Us_Get(id)->mm;
    if (v > 0) { return (float)v / 10.0f; }   /* 正常：mm → cm */
    return fallback_cm;                        /* 负状态码：按"很远"处理或按策略处理 */
}

void Avoid_Step(void)
{
    float l = Us_DistanceCm(US_L, 400.0f);
    float r = Us_DistanceCm(US_R, 400.0f);
    if (l < 30.0f || r < 30.0f) { /* 触发避障策略：转/停 */ }
}
```

**A02 注意**

| # | 注意 |
|---|---|
| 1 | **必须先判负状态码**（`mm <= 0` 是故障/未测到，不是"距离很近"）|
| 2 | 主循环的自动测量节奏是 **250ms 一颗（左右各 2Hz）** —— 高速时这个刷新率够不够要考虑；`AUTO 0` 可以接管自己控制节奏 |
| 3 | 探头**距反射面 ≥25~30cm** 才可靠，**障碍物太近会测不到**（<20cm 成功率 37~58%）→ 策略里要有"最近处测不到"的兜底 |
| 4 | 两颗**不能同时触发**，自己控制节奏时要保证间隔 |

## 六、自检命令总表（串口 115200，回车结尾）

| 命令 | 作用 |
|---|---|
| `PING` | 连通性：回 `$E,<ms>,90,PONG` |
| `GET` | 打印参数快照（`$P`）|
| `SET <名> <值>` | 在线改参数：`kp` / `ki` / `kd` / `base_speed` |
| `US [id n]` | 测超声波：`id` 省略=两颗都测，`0`=左，`1`=右；`n`=次数（≤30）|
| `AUTO 0\|1\|2\|3` | 主循环自动测：`0`=关 · `1`=左右轮流 · `2`=只左 · `3`=只右 |
| `GR` | 灰度：ping + 数字量 + 8 路模拟量 |
| `GRSCAN` | 扫 I2C1 总线（测灰度接线/上拉/地址）|
| `OLSCAN` | 探 OLED 地址（0x3C/0x3D）|
| `OLED` | 初始化 + 画棋盘测试图案 |
| `OLEDTXT` | 中英文混排测试页（报告缺失字符）|
| `MOT <l> <r>` | 电机：左右占空比 −100~100 |
| `STOP` | 停（滑行）|
| `BRAKE` | 刹车 |
| `ENC` | 打印左右编码器计数 |
| `ENCRESET` | 编码器清零 |
| `KEY` | 读按键状态 |
| `BEEP [ms]` | 蜂鸣器响（默认 300ms）|
| `MPU` | MPU6050：WHO_AM_I + 加速度 + 角速度 + 温度 |
| `BT <文字>` | BLE 发一句给手机 |
| `BTBAUD <n>` | 改 BLE 通道波特率 |
| `BTAT` | 以当前波特率发 `AT` 并打印模块回的字节 |

**命令是在主循环里执行的**（`Tlm_Poll()`），中断里只收行 —— 所以命令执行期间主循环会停一下，属正常。
