# 留言板 · 固件

> **用途**：固件/算法区**内部**的交接 / 意图 / 提醒（A01 ↔ A02 ↔ P01/P02）。跨区的事写仓库根 `留言板.md`。
> **读**：在本区（`firmware/`）动手前，先读本板 + 仓库根 `留言板.md`。
> **写**：一条 **≤3 行、≤150 字**（**事 / 依据 / 要对方**）；**必须署名**；**单独提交**；
> **只改自己的留言**；提交后在当轮回复末尾**贴出来给组长过目**（有异议由作者撤回并提交清空）。
> **别写**：进度（→ `项目记录/实际进度.md`）、方案长文（→ `firmware/文档/` 或 `项目记录/`，这里只留一行指针）、数据（→ `logs/`）。
> **上限 20 条**：超出时把最旧的移进 `留言板归档_YYYY-MM.md`。
> 完整规则见 `docs/文档维护.md` §留言板。
