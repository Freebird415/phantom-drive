# v11 · A02 三段固定轨迹（快照 · 暂不使用）

> 日期：2026-10-18 ｜ 类型：A02 固定轨迹的**参数快照**（代码里保留能力，但当前**停用**）
> 当前实际使用：**① 推出 + ② 定时线性回摆（两段）**，见 `firmware/src/app/avoid_path.c` 顶部调参区。

## 1. 这份快照是什么

`avoid_path.c` 支持三段轨迹，第三段（回正 `ALIGN`）已经写好并测试过，但为了**先把两段轨迹跑稳**，
现在把 `AV_ALIGN_*` 全部置 0（不启用）。这里把当时测出来的一套第三段参数留档，随时可填回去。

## 2. 快照参数（当时测试值）

| 段 | 参数 | 值 |
|---|---|---|
| ① 推出 OUT | `AV_OUT_MS` / `AV_OUT_L_PWM` / `AV_OUT_R_PWM` | 400u / 0 / 48 |
| ② 回摆 RETURN | `AV_RETURN_MS` | 2000u |
| | `AV_RET_START_L_PWM` / `AV_RET_START_R_PWM` | 40 / 25 |
| | `AV_RET_END_L_PWM` / `AV_RET_END_R_PWM` | 45 / 25 |
| ③ 回正 ALIGN（**快照，当前为 0**）| `AV_ALIGN_MS` | 4000u |
| | `AV_ALIGN_START_L_PWM` / `AV_ALIGN_START_R_PWM` | 30 / 35 |
| | `AV_ALIGN_END_L_PWM` / `AV_ALIGN_END_R_PWM` | 34 / 35 |

> 左避（右侧障碍）视角；向右避时左右轮自动对调。
> 转向规则：**右轮比左轮快 ⇒ 向左转**；左轮比右轮快 ⇒ 向右转。

## 3. 怎么恢复三段

只改 `avoid_path.c` 顶部这 5 个宏（填上表里的值），重编译烧录即可，**不用改代码逻辑**：

```c
#define AV_ALIGN_MS            4000u
#define AV_ALIGN_START_L_PWM     30
#define AV_ALIGN_START_R_PWM     35
#define AV_ALIGN_END_L_PWM       34
#define AV_ALIGN_END_R_PWM       35
```

启用条件：`AV_ALIGN_MS > 0` 且 4 个 PWM 里至少有 1 个非 0。

## 4. 注意（恢复后要一起改的地方）

- `Path_ReturnExpired()` 在**有回正段**时不再算超时失败，超时点顺延到 `Path_AlignExpired()`；
- 三段合计时长 = `AV_OUT_MS + AV_RETURN_MS + AV_ALIGN_MS`，这段时间就是"判线窗口"；
- 判线参数（`A02_LINE_IGNORE_MS / WINDOW / GAP / BLACK_COUNT`）不受影响。
