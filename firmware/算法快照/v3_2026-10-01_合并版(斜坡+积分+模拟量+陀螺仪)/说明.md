## 二、两个新开关怎么用（现场 A/B）

```
ANALOG 1     # 用模拟量求误差（推荐试；自标定约 0.2 秒建立，范围不够会自动退回数字量）
ANALOG 0     # 退回数字量
GYROD 1      # 陀螺仪阻尼（未验证，可能让转弯变钝 —— 试的时候留意）
SET ki 0     # 关掉积分，回到纯 PD
SET ki 0.05  # 恢复默认
```
> 状态码不变：0=丢线/待机 · 1=循迹 · 5=起步找线 · 4=精停
> 参数不持久（断电丢）—— 定稿要写回 `app_telemetry.c` 的 `s_p` 默认值 ✓

## 三、模拟量自标定的原理（为什么不用人工标定）

拿**数字位当“老师”**：数字说第 i 路“黑”，就把第 i 路当前的模拟值往“黑基线”拉一点（反之往“白”）。
用时约 0.2 秒建立；黑/白基线差 < 30 就认为没就绪 ⇒ **自动退回数字量** ✓（不会因为标定没建好而乱跑）
极性也不用管：用 `|a−白|/|白−黑|` 取幅值 ✓
