## 1. 这一版是什么

在 v11（A02 两段轨迹 + 回线 v3 + 慢速 A01 + 终点冲刺）基础上，**唯一新增的功能是「A01 循迹中脱线的自动回线」**，其余行为与"桌面兜底版"完全一致（桌面那份保留为不带本功能的回退版）。

| 能力 | 状态 |

| A01 循迹（PID + 曲率风险降速 + 宽黑区走直线）| 沿用 |
| A02 避障（400mm 预备 / 310mm 触发 / 两段轨迹 / 回线 v3 旋转摆正）| 沿用 |
| 终点精停（30s 时间闸 + 300ms 八路扫过 + 八路全白 ⇒ 冲刺 100ms@70% ⇒ 刹停）| 沿用 |

| **A01 脱线自动回线（本版新增）** | **新增** |

## 2. 新增功能：A01 脱线回线

**只在这一个场景触发**：A01 正在正常循迹（`state=1`）、车在行驶、灰度在线，突然**八路全白**。

**绝不触发**的场景（由代码路径或门禁保证）：

| 场景 | 为什么不触发 |
|---|---|
| A02 避障 / 回线全过程 | 主循环此时调用的是 `Avoid_Step()`，`Trace_Step()` 根本不执行 |
| A02 刚交还、还没看到线 | `s_seek=1`，走"起步找线"分支（26/26 直行）|
| 精停 / 终点冲刺段 | 终点状态机在前且已 `return` |
| 灰度离线 / `TRACE 0` / 停车 | `allow_drive=0`，不驱动电机 |
| 刚压过横向黑条（T 头、赛道标识）| `A01_LOST_TBAR_MS` 内出现过"同一拍八路全黑"⇒ 否决，走保守刹车 |

**动作时序**：

```
八路全白第 1 拍：判定方向并锁存（之后不再改）
  ├─ 方向 = sign(err)，取宽黑 clamp【之前】的 err（s_last_line_err_raw）
  │    err > +0.5 ⇒ 车向左冲出、线在右侧 ⇒ 车头向右摆
  │    err < -0.5 ⇒ 车向右冲出、线在左侧 ⇒ 车头向左摆
  │    |err| ≤ 0.5 或 刚过黑条 ⇒ 不找回，走保守：直行 200ms → 刹停 + 锁存
  ↓
① 0~150ms        直行 26/26（跨胶带接缝/短空白）
② 刹停 60ms      消前进惯性
③ 原地旋转       L=±8 / R=∓20（**沿用 A02 回线的同一组数值**，每 10ms 变 2）
                 一旦「第 3~6 路有相邻两路黑 且 第 1/2/7/8 路全白」⇒ 线已居中
④ 保持 100ms     复核居中 ⇒ 交回 A01 循迹（自动进 3.5s 慢速窗口）
   · 旋转 3000ms（≈一整圈）仍找不到 ⇒ 刹停 + 锁存
```

**可以连续执行**：一次找回成功后立即允许下一次（无冷却），且会**重新判一次方向**。
**锁存释放**：按按钮重新发车、串口 `FINRESET`、或断电。

## 4. 怎么编译 / 烧录

```bash
pio run -d firmware                    # 只编译
pio run -d firmware -t upload          # 编译 + ST-Link 烧录
python tools/flash.py                  # 一键：编译 + 多策略重试 + 中文诊断
```

两个配置都必须能编过（改动后请各跑一次）：

| 配置 | 含义 |
|---|---|
| `A01_LOST_SEARCH 1` | 正式版（默认）|
| `A01_LOST_SEARCH 0` | 回退版：不旋转，全白 200ms 后刹停 |
