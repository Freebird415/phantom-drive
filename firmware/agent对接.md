## 2. 硬限制（破了多半被编译守门或实车打回）

### 2.1 Flash / RAM 预算（余量告急）

- **固件必须 < 54KB**：板载快照保留区从 `0x0800D800` 起 ⇒ 固件不得压进去（`check_size.py` 编译后自动拦，**超了直接编译失败**）。
- **2026-10-10 实测：50.9KB / 54KB（余量仅 7.9%，≈4.4KB）**；RAM **11.4KB / 20KB**。
- 省体积三条铁律：
  1. **禁止 `%f` / `%g` 打印**（会拉 ~9KB 库）⇒ 定点输出用 `Bsp_FmtFix()`；
  2. **禁止 `atof` / `strtod` / `sscanf("%f")`** ⇒ 用 `parse_float` / `parse_int`；
  3. 不加大表 / 大数组 / 新缓冲；要加先算预算。
- 加不下时，先删/压缩**自己文件里的**旧代码，**不要**动别人的。

### 2.2 只能用驱动接口，不碰硬件

- 只用 `drv_*`：`Gr_ReadDigital`、`Mo_Set`、`En_Count`、`Tlm_SendT`、`Log_GetGz` …；**不要**直接读写寄存器/外设，**不要**新增引脚。
- `Log_GetGz()` 返回**原始 LSB**（**131 LSB = 1°/s**）⇒ 用前要 `/131`；而 `$T` 里的 `gz8` 是 **2°/s per LSB**——**两个不是同一个量，别混用**。
- ⚠️ **陀螺当前有已知失效**（`决策登记` O-10：v4 两趟共 1314 个 `$T` 帧 `gz` 恒 0）：**任何依赖 gz 的算法必须先做"有效性/新鲜度"判定**；零反馈时不得继续积分航向、不得持续打舵，应降级或停车。
- 接口清单与调用骨架见 `文档/驱动接口说明.md`；**以各 `src/drv/drv_xxx.h` 头注释为权威**。

### 2.3 协议与状态码已冻结

- `$T/$P/$E/$U` 帧格式与字段顺序见 `docs/遥测协议.md`：**新字段只能加在行尾**；
- `state` 码固定：0 待机/丢线 · 1 循迹 · 2 避障 · 3 回线 · 4 精停 · 5 起步找线 · 6 丢线找线 —— **不要占用或改义**；
- 驱动接口 **10/12 冻结**后只加功能、不改接口。

### 2.4 发车安全

- `TRACE 0` / `AVOID 0` = 只算不发（`$T` 照报，电机不动）；要驱车必须显式开，且**第一次先把轮子架空**；
- 避障接管期间，主程序让循迹**只算不发**（`Trace_Step(0)`）—— A02 不要去调 A01 的状态，A01 也不要改 A02 的接管标志。

## 3. 目录地图（改目录前先看）

```
firmware/
├── README.md               人类入口：要求 / 接线 / 命令 / 怎么用
├── agent对接.md            本文件：给 AI 的边界与约束
├── 留言板.md                区内交接板（A01 ↔ A02 ↔ P01/P02）
├── platformio.ini           PlatformIO 工程配置（+ `extra_scripts: check_size.py`）
├── check_size.py            编译后体积守门（**构建挂钩，必须与 platformio.ini 同级**）
├── src/                     ★ 只有会编进固件的源码放这里（PlatformIO 递归编译）
│   ├── main.c               唯一的 main：初始化 + 主循环 + 仲裁
│   ├── app/                 应用层：app_trace(A01) · app_avoid(A02) · app_log · app_telemetry
│   ├── drv/                 器件驱动（车上每个模块一对 drv_xxx.{c,h}）
│   └── bsp/                 板级资源（时钟 / 计时 / 串口 / 指示灯…）
├── include/                 头文件目录占位（PlatformIO 约定）
├── 文档/                    驱动接口说明等固件文档
├── 测试/                    上位机回归/诊断脚本（Python，不参与编译）
└── 算法快照/                 各版 app_trace.c / 集成版存档 + 说明（对比、回退用）
```

规则：**分层只看依赖方向**（`app → drv → bsp`，不准反向）｜**一个器件一个文件**｜**不在 `src/` 放非源码**（日志/截图/说明都放外面）。

## 4. 改完怎么验证（**不实测不算完成**）

| 场合 | 怎么做 |
|---|---|
| 编译 | `pio run -d firmware` —— 零 warning 才算过（体积守门会顺带报 Flash/RAM） |
| 台面（车在桌上、能插线） | 双击根目录 `工具箱.bat` → 看串口；或 `python tools/run.py --note "..." --seconds 20` |
| 跑车（插不了线） | 双击 `蓝牙日志.bat` 无线收流；要 100Hz 全精度用 `tools/snapshot.py` 读板载快照 |
| A02 回归 | `python firmware/测试/a02_regression.py`（另有 `a02_navigation.py`、`a02_gyro_diagnostic.py`） |
| 留档 | 日志 + 一句话结论；给别人看用 `logs/共享_*.md`（**原始 CSV 不入库**） |
