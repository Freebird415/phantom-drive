## 二、怎么读

- **网络名 = 嘉立创 EDA 里的网络标号**：两边同名即同一根线。电源（`5V`/`3V3`/`GND`/`12V`）同样用网络标号表示，不画共用母线。
- 图 `01` 是唯一的**元件级**电路；`02~04` 是**模块级接线图**，模块内部细节由 H02 在 EDA 里落。
- 灰色斜体小节 = 关键约束与动机（为什么要这么接）。

## 四、本版相对 v0.1 的变化（都是实测/手册驱动的）

| 变化 | 原因 |
|---|---|
| 灰度主方案改为 **感为（I2C1）**，亚博降为备用，两座均为 **16P** | 实物针序：感为 `GND,5V,KEY,Err,1..8,CLK,DAT,SCL,SDA`；亚博 `5V,GND,KEY,RESET,X1..X8,TX,RX,SCL,SDA` → 针 1/2 反相，必须各占一座 |
| **OLED / MPU6050 从灰度的 I2C 挪到 I2C2（3.3V 上拉）** | 感为板载上拉是 **5V**（手册明确），共用会把 3.3V 器件打坏 |
| **PC14/PC15 标记为不可用** | 实物照片确认板上有 32.768kHz 晶振；可用 IO 从 35 降到 **33** |
| **3.3V 改由核心板 RT9193 输出**（方案 A） | 2026-09-20 决策：本板只送 5V，禁止两枚 LDO 对打；BOM 的 5V→3.3V 模块**不装** |
| 保险丝 2A → **3A 慢断** | 两台 JGB37-520 同时启动浪涌 >2A |
| 电机接口 → **JST-XH 6P 现成座** | 用户决策 + 实物插头照片；取消大电流焊盘方案 |
| 新增 **蜂鸣器 / 用户按键 / 12V 指示灯** | 用户决策（全要） |
| PWM 从 TIM3 挪到 **TIM4**，编码器右改 **TIM3** | 让 PB0 空出来做 ADC 电压检测（PB0/PB1 是仅剩的 ADC 脚） |
| STBY 改 **PA11**（带 10k 上拉 + 跳线） | 33 个 IO 已排满；PA11 原为 USB DM，只能作输出，正好 |

## 五、待王政淋校验（校验完与《引脚分配表》一起冻结）

1. **电机 6 芯线实物线序**（必须实测；接错烧编码器）
2. **OLED 具体型号**（拍背面丝印 → 决定 I2C2 上拉是否要焊）
3. **3.3V 负载核算**（核心板 RT9193 ≤300mA 是否够：编码器 2 + OLED + MPU + TB6612 逻辑 + 预留）
4. **编码器 VCC 走 3.3V 还是 5V**（PCB 留跳线，需上车实测）
5. **PCB 外形与安装孔** → 与李昕程《安装接口契约》对齐
6. 保险丝座、P-MOS 选型与封装；大电容体积能否装下
