1. **权威顺序**：`netlist.json`（本目录，由 `生成接线图.py` 生成） > 本文 §3~§6 > 图纸 PDF > 其余文档。

|---|---|

| 电源 | 单块 12V 锂电 → 3A 慢断保险丝 → P-MOS 反接保护 → TB6612 VM；MP1584 → 5V；**3.3V 由核心板 RT9193 输出** |

| 引脚区 | 可用性 | 依据 |

## §2 电源域与上电规则

| 母线 | 来源 | 负载 | 约束 |
|---|---|---|---|
| `12V` | 电池 → 总开关 → 3A 慢断保险丝 → P-MOS 反接保护 | TB6612 VM、MP1584、12V 指示灯 | 大电流路径**不得经过排针**；VM 就近并 470µF/25V + 0.1µF |
| `5V` | MP1584（≥2A） | 感为灰度 33mA、超声波 ×2、HC-06、TB6612 逻辑（也可给 3.3V，见下）、核心板 5V 脚 | 母线并 10µF + 0.1µF |
| `3V3` | **核心板 RT9193 输出**（≤300mA） | 编码器 ×2、OLED、MPU6050、TB6612 VCC、SWD/预留排针 | 本板**不得自身产生 3.3V**；母线并 10µF + 0.1µF |
| `GND` | 单点汇合 | 全部 | 大电流地与信号地单点汇合；全车唯一电池地 |

**上电硬规则（违反会导致两枚 LDO 对打）**
1. 核心板的 `5V` 脚与 `3V3` 脚**只能接一个**。本项目接 `5V`。
2. 本板**禁止**再放 5V→3.3V 模块去驱动 3V3 母线。（原 BOM 的"5V-3.3V 降压模块"在本设计中**不装**；如日后余量不足，必须同时满足：断开核心板 5V 脚、并由本板供 3.3V——这是一次 §9 级变更。）
3. 保险丝**3A 慢断**（两台 JGB37-520 同时启动的浪涌 >2A）。

## §4 网络级电气要求（逐条强制）

### 4.1 按钮 / 指示
| 网络 | 要求 | 动机 |
|---|---|---|
| `KEY` | PB2 → 按键 → GND；PB2 侧 10k 上拉到 3V3，并 100nF 到 GND | 无上拉时按键悬空会乱跳；RC 去抖省掉软件抖 |
| `BUZZER` | PB1 → 1k 基极电阻 → NPN（S8050/MMBT3904）→ 有源蜂鸣器 → 5V；蜂鸣器两端并反向续流二极管 | 蜂鸣器 20~30mA 超 GPIO 能力；感性负载无续流会打坏三极管 |
| `LED_12V` | 12V → 1k → LED → GND | 指示总电源已上；不占 IO |

### 4.2 I2C 两条总线（**本设计最容易出错的地方**）
| 项 | I2C1（灰度） | I2C2（OLED + MPU6050） |
|---|---|---|
| 引脚 | PB8 (SCL) / PB9 (SDA)，`__HAL_AFIO_REMAP_I2C1_ENABLE()` | PB10 (SCL) / PB11 (SDA)，无重映射 |
| 供电 | 模块 5V | 模块 3.3V |
| 上拉源 | **5V**，10k | **3.3V**，4.7k（模块自带上拉时可空焊） |
| 上拉由谁提供 | **感为模块板载上拉跳线帽**（板载 5V/10k）；PCB 侧**不要**再放 3.3V 上拉 | PCB 侧 4.7k 焊盘（默认焊） |
| STM32 侧可行性 | PB8/PB9 为 FT（5V 容忍）引脚，open-drain 模式下允许 5V 上拉 | 普通 3.3V 总线 |

> ⚠️ **两条总线绝不可并联**。I2C1 被上拉到 5V，而 OLED / SSD1306 与 MPU6050 的 SDA/SCL 绝对最大额定值约为 VDD+0.3V=3.6V —— 5V 上拉会**损坏**这两个器件。这是本次设计把 OLED/MPU6050 从 I2C1 挪到 I2C2 的唯一原因。
> ⚠️ 感为手册原文："板载的上拉源为 5V, 10kΩ，请详细查阅您所用主控数据手册，以验证是否兼容"。若外置上拉，**上拉源不得低于 72% 供电电压**，电阻取 **1k~10k**。
> ⚠️ 感为 I2C 地址：7bit = `0b1001 11 AD1 AD0`（AD1/AD0 为板上跳线帽）。**不装跳线帽 = 0x4C**；两颗都装 = 0x4F（HAL 里用 7bit 地址左移，即 `0x4C<<1`）。

### 4.3 灰度（主：感为 / 备：亚博）
| 项 | 感为（主） | 亚博 YB-MUX04（备） |
|---|---|---|
| 连接器 | **1×16P / 2.54mm 排母**（与模块的 16pin 排针直插） | 同型 **1×16P 排母**，**独立座** |
| 关键差异 | 针 1=GND、针 2=+5V | 针 1=5V、针 2=GND（**与感为相反**） |
| 本设计使用 | 5V/GND + 针 15 SCL / 针 16 SDA（I2C） | 5V/GND + 针 15 SCL / 针 16 SDA（I2C） |
| 其余脚 | 针 5~12（并行 1~8）**不接**；针 13/14（CLK/DAT 串行）引到排针**备用**；针 3 KEY、针 4 Err 悬空 | 针 5~12（X1~X8）不接；针 13/14（TX/RX）引到排针备用；针 4 RESET 悬空 |
| 为什么两个座 | 针 1/2 相反 → 共用一个座会把 5V/GND 接反，**反接必烧** | 同上 |

> 设计动机：只走 I2C 的原因是能把 8 路并行线（8 个 IO）全省下来；感为的 I2C 还能读到**模拟量**（并行/串行只能读数字量），对 PID 更好。
> 备选升级路径：若日后需要更细的模拟量或更低延迟，感为可切**并行**模式（针 5~12），但那需要 8 个空闲 IO——当前**没有**，属 §9 变更。

### 4.4 超声波
| 网络 | 要求 | 动机 |
|---|---|---|
| `US_x_TRIG` | 两个模块各自独立 Trig，**不得并联** | 同时发波会互相收到对方的回波（串扰） |
| `US_x_ECHO` | 串联 1k + 2k/3.3k 分压（5V → 3.11V），或 1k 串 + 3.3V 钳位 | Echo 为 5V 推挽输出；分压同时抑制走线串扰 |
| 软件要求（记录给 A02）| 两次测距间隔 ≥60ms；起终点附近设"禁避障区" | 余波未衰会读错；超声波会把光电门立柱当障碍 |

### 4.5 电机大电流与编码器（**同一根排线**）
- 每个电机一个 **JST-XH 6P 座**（现成插头，BOM 已有）：`M+ / M− / 编码器VCC / GND / A / B`。
- ⚠️ **电机电流与编码器信号走同一根 6 芯排线** → 换向/PWM 噪声会耦合进 A/B，可能丢计数。应对：
  1. A/B 在 PCB 侧各串 100Ω + 并 1nF（RC 低通，截止 ≈1.6MHz，远高于编码器频率）；
  2. 编码器 VCC 就近并 100nF；A/B 预留 4.7k 上拉焊盘（推挽输出时空焊）；
  3. 固件对编码器做"最大跳变"过滤。
- ⚠️ JST-XH 触点额定约 3A；JGB37-520 堵转可到 2A+。**堵转不要久留**，否则座子发热。
- ⚠️ 6 芯线序：BOM 资料索引给出的常见线色（红 M+、白 M−、蓝 编码器VCC、黑 GND、黄 A、绿 B）**不同批次可能不同** —— **必须实测复核后**才能定 PCB 焊盘顺序。A/B 接反只需软件换向，不需改板；**VCC/GND 接反会烧编码器**。

### 4.6 其他
| 网络 | 要求 |
|---|---|
| `VBAT_SENSE` | 12V → 100k → 中点 → 10k → GND；中点并 100nF；只做低压告警 |
| `NRST` | 核心板 `R` 脚 → SWD 排针第 4 针；靠近排针并 100nF 到 GND（可选） |
| `SWDIO/SWCLK` | 直连排针，不加上拉（核心板自带） |
| `UART1_TX/RX` | 直连 XH2.54-4P + 并排排针；TX 串 100Ω 可选 |
| 所有对外接口 | **带扣座子（XH2.54 / PH2.0）+ 并排 2.54 排针**双份；丝印必须印出引脚名 |

## §5 软件侧配套约定（配置固定值，写固件必须照此）

```c
/* 时钟：HSI 8MHz → PLL → 64MHz（不用 HSE） */
/* 关闭 JTAG、保留 SWD —— 释放 PA15 / PB3 / PB4 */
__HAL_AFIO_REMAP_SWJ_NOJTAG();
/* I2C1 重映射到 PB8/PB9 —— 把 PB6/PB7 让给 TIM4 PWM */
__HAL_AFIO_REMAP_I2C1_ENABLE();
/* 定时器：TIM2=左编码器  TIM3=右编码器  TIM4=PWM(20kHz)  TIM1=空闲  SysTick=1ms */
/* 超声波回波计时：DWT->CYCCNT，不占定时器与引脚 */
/* 感为灰度 I2C 7bit 地址：0x4C（默认）/ 0x4F（AD1、AD0 都装跳线） */
```

> `HAL_Init()` 会开 SysTick 中断，**必须自己实现 `SysTick_Handler`**，否则程序会跳进默认处理器死循环（现象：灯不闪、串口无输出）。

## §8 布局/走线约束中与电气相关的部分

1. 12V / 5V / 3.3V / GND **各留 ≥1 个测试点（TP 焊盘）**。
2. 大电流路径（12V → TB6612 → JST-XH → 电机）线宽 ≥2mm 或铺铜；**不经过排针**。
3. 大电流地与信号地**单点汇合**；TB6612 的 VM 就近并 470µF。
4. 灰度的 5V 支路单独走线，并在座子附近加 100µF + 0.1µF（手册要求电压稳定）。
5. 编码器 A/B 与电机线虽然是同一座子，但**PCB 上 A/B 走线要远离 PWM 与电机输出**，必要时加地线隔离。
6. SWD 排针、预留排针、各接口座**装车后仍能插拔**（排针朝天或侧面）。
7. 每个模块接口的 5V 支路串 **0Ω 跳线或自恢复保险丝**，挑故障时可单独断开。

## §9 什么能改 / 什么不能改

### 9.1 红线（改了必须走变更流程，否则视为错误输出）
- 引脚分配（§3）——尤其是 USART1、SWD、I2C1/I2C2 的引脚与定时器通道。
- 两条 I2C 总线的**上拉电压**（5V vs 3.3V）与**不得并联**。
- 核心板 `5V` / `3V3` 脚二选一；本板不得自行产生 3.3V。
- 感为与亚博**必须各占一个独立座**（针 1/2 反相）。
- 保险丝 3A 慢断；反接保护不得省。
- 超声波两个 Trig 独立；Echo 必须分压。
- 电机大电流不得走排针。

### 9.2 可自由改动（改完只需在提交信息里说明）
- 人机部分：蜂鸣器/按键/指示灯的引脚（§3.4）与具体电路形式。
- 预留排针的数量与排布（但必须保留 ≥4 路空闲 IO + 3V3/5V/GND/12V）。
- 电容容量（不小于本规范给定值）、上拉电阻具体阻值（在 §7 允许区间内）、座子型号（同间距同针数即可）。
- 布局、丝印文字、板外形（在《车架与 PCB 对接约定》范围内）。

### 9.3 变更流程
1. 在 `hardware/` 目录下开分支或直接改前**先在群里说明**；
2. 修改 `生成接线图.py` 的 `PINMAP`/`FIGS` 或本文件对应小节；
3. 重跑 `python 生成接线图.py --build`，把 PDF/PNG/接线表/netlist.json 一起更新；
4. 同步 `docs/引脚分配表.md`（冻结后需**李沛阳 + 王政淋双方确认**）与 `项目记录/开发记录.md`；
5. **提交需要用户确认**（见根目录 `AGENTS.md` 硬规则 2）。
