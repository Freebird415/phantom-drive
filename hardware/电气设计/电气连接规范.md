## §0 使用说明（给 agent）

1. **权威顺序**：`netlist.json` > 本文 §3~§6 > 图纸 PDF > 其余文档。冲突时按此取值，并在输出里报出冲突，**不要自行折中**。
2. **不要手改 `netlist.json` / `接线表.md` / PDF**：它们是 `生成接线图.py` 的产物。改数据 → 改脚本顶部 `PINMAP` / `FIGS` → 重跑 `python 生成接线图.py --build`。
3. **交付前跑一遍 `python 自检.py`**（三遍检验：结构性 / 一致性 / 需求与手册闭环），退出码必须为 0。
4. 凡本文未定义的网络，视为"不存在"，不要自行新增。需要新增 → 走 §9。

## §2 电源域与上电规则

| 母线 | 来源 | 负载 | 约束 |
|---|---|---|---|
| `VCC`（原文档的 `12V_RAW`） | 电池 / DC005 座 | 总开关 | as-built：板上**无保险丝、无反接保护** —— 反接 12V 会直通下级 |
| `+12V`（原文档的 `12V_BUS`） | 总开关（SS-12D10：2=VCC、1=+12V、3=NC） | TB6612 VM、MP1584 输入 | 大电流路径**不得经过排针**；VM 就近并 470~1000µF（as-built 未装，模块自带小电容） |
| `5V_BUS` | MP1584（≥2A） | 感为灰度 33mA、超声波 ×2、编码器 ×2 VCC、核心板 5V 脚、蜂鸣器模块 U20、TTL 座第 4 针 | 10µF + 0.1µF（as-built 未装）；灰度座附近 100µF + 0.1µF（手册要求，建议补） |
| `3V3_LOGIC` | **核心板 RT9193 输出（≤300mA）** | MPU6050、BLE、TB6612 VCC、SWD/预留、核心板自身 | 本板**不得**自身产生 3.3V；I2C2 上拉由 MPU 模块自带（as-built） |
| `GND` | 单点汇合 | 全部 | 大电流地与信号地单点汇合；全车唯一电池地 |

> **网名对照**（看原理图/PCB 时用）：文档 `12V_RAW` = EDA `VCC`；文档 `12V_BUS` = EDA `+12V`；其余同名。

**上电硬规则（违反会导致两枚 LDO 对打）**
1. 核心板 `5V` 脚与 `3V3` 脚**只能接一个**（本项目接 5V）。
2. 本板**禁止**再放 5V→3.3V 模块驱动 3V3 母线（BOM 里的“5V-3.3V 降压模块”**未装**）。
3. ⚠️ 电池反接无保护（as-built；**组长 2026-10-10 确认板上确实没有**）：上电前必须先核极性；若要保，只能**外部**在电池线里加保险丝 + 反接保护（板上没位置／没装）。
4. 原计划的“DC 座 → T3A 保险丝 → AO4407A → 总开关”**未落到板上**；实际顺序：DC 座 →（裸线）→ 总开关 → +12V。
5. MP1584 **首次上电必须脱机**把 OUT 调到 5.0V 再接后级。

### §3.5 预留（3 路，需关 JTAG）
`PA15`、`PB3`、`PB4` → 2×4 排针（另带 3V3 / 5V / GND×2 / 12V）。

> **关 JTAG 的代价与补偿**：关 JTAG（`__HAL_AFIO_REMAP_SWJ_NOJTAG()`）只是为换来这 3 个脚；
> 代价是必须能"连接下复位" → **NRST 必须引到 SWD 排针**。
> 核心功能**不依赖**关 JTAG：右超声波 Echo 特意放在 PB5。

## §4 网络级电气要求（逐条强制）

### §4.1 按钮 / 指示 / 蜂鸣
| 网络 | 要求 | 动机 |
|---|---|---|
| `KEY` | PA12 → 按键（A12SW）→ GND | 核心板 PA12 上已有 1.5k 上拉，无需再加 |
| `BUZZER` | PB15 → **蜂鸣器模块 U20 的 I/O（2 脚）**；U20：1=VCC(**5V_BUS**)、3=GND | **as-built：模块自带驱动，不需要三极管/基极电阻/续流二极管**（面包板那套已废弃）。若换裸有源蜂鸣器才需要三极管 |
| ~~`LED_12V`~~ | **板上未装 12V 指示灯**（as-built） | 上电指示改看核心板 PC13 心跳灯 |

### §4.2 I2C 两条总线（**本设计最容易出错的地方**）
| 项 | I2C1（灰度） | I2C2（MPU6050） |
|---|---|---|
| 引脚 | PB8 (SCL) / PB9 (SDA)，`__HAL_AFIO_REMAP_I2C1_ENABLE()` | PB10 (SCL) / PB11 (SDA)，无重映射 |
| 供电 | 感为 5V_BUS | 3V3_LOGIC |
| **上拉源** | **5V** | **3.3V** |
| 上拉实现 | **板上无上拉电阻**（as-built）⇒ 感为模块板载「SCL上拉/SDA上拉」5V 跳帽**必须插**（若模块也没有，飞线 4.7k~10k 到 5V） | **板上无上拉**（as-built）⇒ 靠 MPU6050 模块自带 4.7k（GY-521 有）；换裸芯片需补 |
| STM32 侧 | PB8/PB9 为 FT（5V 容忍）引脚，open-drain 模式允许 5V 上拉 | 普通 3.3V 总线 |

> ⚠️ **为什么必须是 5V**：感为手册原文「如果外置上拉源，灰度传感器要求**总线最低上拉源为 72% 的供电电压**，如果低于这个电压阈值**通讯极易失败**」→ 72%×5V = **3.6V**，3.3V 不达标。手册另要求外置上拉电阻取 **1k~10k**。
> ⚠️ **两条总线绝不可并联**：I2C1 被上拉到 5V，而 MPU6050 的 SDA/SCL 绝对最大额定值约 VDD+0.3V=3.6V —— 5V 上拉会**损坏**它。这是把 MPU6050 单独放 I2C2 的原因（OLED 已于 2026-10-10 放弃）。
> ⚠️ 感为 I2C 地址：7bit = `0b1001 11 AD1 AD0`。**不装跳线帽 = 0x4C**；两颗都装 = 0x4F（HAL 用 7bit 地址，传 `0x4C<<1`）。

### §4.3 灰度（感为，板载 1×4P）
| 项 | 值（as-built，2026-10-10 校正） |
|---|---|
| 连接器 | 板载 **1×4P / 2.54mm**（丝印 `灰度4pin`）：1=GND、2=+5V、3=SCL、4=SDA |
| 感为模块侧用针 | 模块 16P 里只用 4 根：1=GND、2=+5V、15=SCL、16=SDA（其余脚悬空） |
| 上拉 | **板上无上拉电阻** ⇒ 感为模块板载 5V/10k 跳帽【必须插】（手册：上拉源 ≥3.6V） |
| 亚博备座 | **未落到板上**（原计划的独立 16P 座不存在；备用方案需飞线/外接） |

> 设计动机：走 I2C 可省下 8 个并行 IO；**感为的 I2C 还能读到模拟量**（并行/串行只能读数字量），对 PID 更有利。
> ⚠️ 感为手册要求**供电稳定**（电机启停尖峰）：座子附近建议加 100µF + 0.1µF（as-built 未装，属建议补强）。

### §4.4 超声波
| 网络 | 要求 | 动机 |
|---|---|---|
| `US_L_TRIG` / `US_R_TRIG` | **各自独立引脚，不得并联** | 同时发波会收到对方回波（串扰） |
| `US_L_ECHO` / `US_R_ECHO` | **as-built 分压**：Echo → **2k（R3/R4）串** → 节点（→PA5/PB5）→ **1k（R5/R6）+ 2k（R1/R2）= 3k 下臂** → GND ⇒ 5V×3/5 = **3.0V** | Echo 为 5V 推挽输出；分压同时抑制串扰。⚠️ R1/R2 的器件库描述曾写 3.3kΩ（与位号 `R1=2k` 矛盾）—— 以**实际装配 2k** 为准（2026-10-10 组长已换正确阻值）|
| 软件（记录给 A02）| 两颗**不得同时触发**，用"左测→等待→右测→等待"轮询；两次间隔 ≥60ms；起终点附近设"禁避障区" | 余波未衰会读错；超声波会把光电门立柱当障碍 |

### §4.5 电机大电流与编码器（**同一根 6 芯线**）
- 每个电机一个 **JST-XH 6P 座**（电机自带线束），**实测针序**：

  | 针 | 1 | 2 | 3 | 4 | 5 | 6 |
  |---|---|---|---|---|---|---|
  | 信号 | `M1` | `GND` | `C2` | `C1` | `VCC(+5V)` | `M2` |

  左电机：M1→TB6612 AO1，M2→AO2，C1→PB6，C2→PB7；右电机：M1→BO1，M2→BO2，C1→PA6，C2→PA7。
- ⚠️ **线序仍须通断复核**（王政淋已在旧板实测确认，新线束可能有差异）；**A/B（C1/C2）接反只需软件换向，VCC/GND 接反会烧编码器**。
- ⚠️ **电机电流与编码器信号走同一根线** → 换向/PWM 噪声会耦合进 C1/C2，可能丢计数。应对：
  1. C1/C2 各串 **100Ω**、可选并 **1nF**（as-built 未装，属建议补强）；
  2. 编码器 VCC 就近并 100nF（as-built 未装）；C1/C2 4.7k 上拉焊盘（推挽输出时空焊）；
  3. 固件对编码器读数做"最大跳变"过滤。
- ⚠️ JST-XH 触点额定约 3A；JGB37-520 堵转可到 2A+ → **堵转不要久留**。
- **编码器 VCC 实测走 +5V**（旧板实物确认）→ C1/C2 电平为 0~5V；所接引脚 PB6/PB7/PA6/PA7 全部是 FT（5V 容忍）数字脚 ✓。

## §5 软件侧配套约定（写固件必须照此）

```c
/* 时钟：HSI 8MHz → PLL → 64MHz（不用 HSE） */
__HAL_AFIO_REMAP_SWJ_NOJTAG();     /* 关 JTAG 留 SWD → 释放 PA15/PB3/PB4 */
__HAL_AFIO_REMAP_I2C1_ENABLE();    /* I2C1 → PB8/PB9，把 PB6/PB7 让给 TIM4 */
/* 定时器：TIM4=左编码器  TIM3=右编码器  TIM1=PWM(20kHz)  TIM2=空闲(不要 remap)  SysTick=1ms */
/* 超声波回波计时：DWT->CYCCNT（不占定时器与引脚） */
/* 感为灰度 I2C 7bit 地址：0x4C（默认）/ 0x4F（AD1、AD0 都装跳线） */
```

> ⚠️ **不要给 TIM2 设置任何 remap**：TIM2 Full Remap 会把 PA2/PA3 复用成 TIM2_CH3/CH4，与 USART2（BLE）抢同一对脚。
> ⚠️ `HAL_Init()` 会开 SysTick 中断，**必须自己实现 `SysTick_Handler`**，否则跳进默认处理器死循环（现象：灯不闪、串口无输出）。
> ⚠️ 若固件跑飞：用 ST-Link **连接下复位**（NRST 已引到排针）；BOOT0 跳线帽可进 Bootloader 救板。

## §8 布局/走线约束中与电气相关的部分

1. 12V_BUS / 5V_BUS / 3V3_LOGIC / GND **各留 ≥1 个测试点（TP 焊盘）**。
2. 电机/12V 大电流回路与 MCU、I2C、蓝牙区域分开；TB6612、MP1584 靠近电源入口和电机接口。
3. 大电流路径（12V_BUS → TB6612 → JST-XH → 电机）线宽 ≥2mm 或铺铜；**不经过排针**、不绕过 MCU/I2C/蓝牙区域；逻辑信号不与电机线长距离平行。
4. 大电流地与信号地**单点汇合**；TB6612 VM 就近并 470~1000µF。
5. 灰度的 5V 支路单独走线，座子附近加 100µF + 0.1µF（手册要求供电稳定）。
6. 编码器 C1/C2 走线远离 PWM 与电机输出，必要时加地线隔离。
7. MP1584 的 SW/电感区域远离蓝牙天线与编码器/I2C；输入输出电容靠近模块。
8. BLE 天线朝板外侧，天线下方与前方**保持无铜/无地/无大金属**的 keep-out。
9. Blue Pill 放在易插拔区域，**USB 口与 SWD 口必须可接近**；SWD 排针、预留排针、各接口座装车后仍能插拔。
10. 每个模块接口的 5V 支路串 **0Ω 跳线或自恢复保险丝**，挑故障时可单独断开。
11. PCB 外形包络暂按约 **120×100mm** 预估，但**最终尺寸、孔径、孔距必须等机械组冻结**，不得自行猜孔位。

## §9 什么能改 / 什么不能改

### §9.1 红线（改了必须走变更流程，否则视为错误输出）
- 引脚分配（§3），尤其 USART1、SWD、I2C1/I2C2 的引脚、PWM 与编码器的定时器通道。
- 两条 I2C 总线的**上拉电压**（5V vs 3.3V）与**不得并联**。
- 核心板 `5V` / `3V3` 脚二选一；本板不得自行产生 3.3V。
- 感为与亚博**必须各占一个独立 16P 座**（针 1/2 反相）→ **as-built 实际为 1×4P，无亚博座**（2026-10-10 校正）。
- **as-built：板上无保险丝/反接保护**（原定的 T3A + AO4407A 未落到板上）。上电前必须核极性；若要保，在**电池线外部**加（板上无位置）。
- 超声波两个 Trig 独立；Echo 必须分压。
- 电机大电流不得走排针；`PB2` 不得接任何信号。
- **不得设置 TIM2 remap**（会与 USART2 抢 PA2/PA3）。

### §9.2 可自由改动（改完只需在提交信息里说明）
- 人机部分：蜂鸣器/按键/指示灯的具体电路形式（§3.4 引脚已定）。
- 预留排针数量与排布（但必须保留 ≥3 路空闲 IO + 3V3/5V/GND/12V）。
- 电容容量（不小于本规范给定值）、上拉电阻阻值（在 §7 允许区间内）、座子型号（同间距同针数即可）。
- 布局、丝印文字、板外形（按与李昕程当面商定的尺寸）。

### §9.3 变更流程
1. 改前**先在群里说明**（涉及引脚/总线必须李沛阳 + 王政淋双方确认）；
2. 修改 `生成接线图.py` 的 `PINMAP`/`FIGS` 或本文件对应小节；
3. 重跑 `python 生成接线图.py --build` 与 `python 自检.py`（退出码必须 0）；
4. 同步 `docs/引脚分配表.md` 与 `项目记录/开发记录.md`；
5. **提交需要用户确认**（见根目录 `AGENTS.md` 硬规则 2）。
