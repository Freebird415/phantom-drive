## 三、各模块接线（按模块看）

### 3.1 感为八路灰度（16P 排针，**主方案**）
| 感为针 | 接到 | 说明 |
|---|---|---|
| 1 | **GND** | 电源负（**注意：1=GND**）|
| 2 | **5V_BUS** | 电源正，33mA |
| 3 KEY | 悬空 | 校准用；**用杜邦线短接 针3↔针1** 代替按键 |
| 4 Err | 悬空 | 错误指示 |
| 5~12 | 悬空（引到排针） | 并行数据，本设计不用 |
| 13 CLK / 14 DAT | 悬空（引到排针） | 串行备份 |
| 15 SCL | **PB8** | |
| 16 SDA | **PB9** | |
> **上拉**：必须 5V → 插上模块板载「SCL上拉/SDA上拉」跳帽（板载 10k）；**不要插 AD0/AD1**（会改地址，驱动按 0x4C）

### 3.2 亚博八路灰度（16P，备用，**独立座**）
| 亚博针 | 接到 |
|---|---|
| 1 | **5V_BUS**（⚠️ 与感为相反：1=5V） |
| 2 | **GND** |
| 3 KEY / 4 RESET | 悬空 |
| 5~12 | 悬空（引到排针） |
| 13 TX / 14 RX | 悬空（引到排针） |
| 15 SCL | **PB8**（与感为共用 I2C1） |
| 16 SDA | **PB9** |

### 3.3 超声波 ×2（HC-SR04，各一个 4P 座）
| | VCC | GND | Trig | Echo |
|---|---|---|---|---|
| **左** | 5V_BUS | GND | **PA4** | **PA5**（串 2k 上 / 3.3k 下分压）|
| **右** | 5V_BUS | GND | **PA1** | **PB5**（同样分压）|
> 两颗 **Trig 必须独立**（不能并联，否则互相收到回波）；固件里“每 **250ms** 一颗、左右轮流”（实测 250ms 成功率 100%；100ms 时左侧掉到 42%）

### 3.4 电机 + 编码器（每个电机一根 6P 线，**实测针序**）
| 6P 针 | 信号 | 左电机接到 | 右电机接到 |
|---|---|---|---|
| 1 | `M1` | TB6612 **AO1** | TB6612 **BO1** |
| 2 | `GND` | GND | GND |
| 3 | `C2` | **PB6**（TIM4_CH1） | **PA6**（TIM3_CH1） |
| 4 | `C1` | **PB7**（TIM4_CH2） | **PA7**（TIM3_CH2） |
| 5 | `VCC` | **5V_BUS** | **5V_BUS** |
| 6 | `M2` | TB6612 **AO2** | TB6612 **BO2** |
> ⚠️ 线序是王政淋在旧板上实测的，**新线束务必先通断复核**；VCC/GND 接反会烧编码器，A/B 反了只需软件改符号

### 3.9 ST-Link（4 线 + 可选）
| ST-Link | 接到 |
|---|---|
| SWDIO | **PA13** |
| SWCLK | **PA14** |
| GND | GND |
| 3V3 | 可选（**蓝板已由 USB/5V 供电时不接**，避免两路电源顶牛） |
| RST | **NRST**（对应 SWD 排针第 4 脚） |

### 3.10 BLE 模块（实物 6P）
| BLE | 接到 |
|---|---|
| VCC | **3V3_LOGIC**（现按 3V3 走线；⚠️ 实物丝印要求 **3.6~6V**，口径待定 —— `决策 E-05`）|
| GND | GND |
| TXD | **PA3** |
| RXD | **PA2** |
| GPIO1 / GPIO2 | 悬空 |
> 仅调试用；比赛时不接（全自动、禁遥控）

### 3.11 用户按键 / 蜂鸣器 / 指示灯
| 件 | 接线 |
|---|---|
| **按键** | **PA12** ── 按键 ── **GND**（按下=低；核心板已有 1.5k 上拉） |
| **蜂鸣器** | **PB15** → 1k → **NPN(S8050) 基极**；发射极 → GND；集电极 → 蜂鸣器 **负极**；蜂鸣器 **正极** → **3V3**；蜂鸣器两端并**续流二极管** |
| **12V 指示灯** | 12V_BUS → 1k → LED → GND |

### 3.12 SWD 排针（1×5）
1 = **3V3** / 2 = **SWDIO(PA13)** / 3 = **SWCLK(PA14)** / 4 = **NRST** / 5 = **GND**

### 3.13 预留排针（2×4）
1 = **PA15** / 2 = **PB3** / 3 = **PB4** / 4 = **3V3** / 5 = **5V** / 6 = **GND** / 7 = **GND** / 8 = **12V**

## 四、上电顺序与安全检查（每次上电照做）

1. 目视：**无短路、极性正确、无裸露线头相碰**
2. 先合 **SW1 总开关** → 看 12V 指示灯亮
3. 听/看：MP1584 无异常发热、无异味
4. 万用表量 **5V_BUS ≈ 5.0V**、**3V3_LOGIC ≈ 3.3V**
5. 核心板 LED 心跳闪烁（500ms 一闪）= 固件在跑
6. 串口发 `PING` → 应回 `$E,<ms>,90,PONG`

**异常处理**：先断总开关，再查线；**任何时候手边都能碰到总开关**

## 五、线材与连接器规范（成品必须遵守）

| 用途 | 用什么 |
|---|---|
| 电池 / 大电流 | **XT30 / XT60 / T 插**（不拆装的直接焊） |
| 电机动力线 | 焊接 或 **XH2.54 / JST-VH** |
| 信号线 | **XH2.54 / PH2.0 带扣插口**（板端用座子） |
| 不拆装的连接 | **直接焊死** |
| 杜邦线 | **仅限面包板调试与 SWD**（振动下会间歇接触不良，是最难查的故障） |
| 电机侧 | 用电机自带的 **JST-XH 6P** 插头（正品带扣） |
