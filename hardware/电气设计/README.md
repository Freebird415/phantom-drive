## 二、怎么读

- **网络名 = 嘉立创 EDA 里的网络标号**：两边同名即同一根线。电源用 `12V_BUS` / `5V_BUS` / `3V3_LOGIC` / `GND` 四个网络名表示，不画共用母线。
- 图 `01` 是唯一的**元件级**电路；`02~04` 是**模块级接线图**，模块内部细节由 H02 在 EDA 里落。
- 斜体小字 = 关键约束与动机（为什么要这么接）。

## 三、怎么改（唯一事实来源）

| 要改的东西 | 改哪里 |
|---|---|
| 引脚分配 | 先改 `../../docs/引脚分配表.md`（冻结后需李沛阳 + 王政淋双方确认）→ 再改 `生成接线图.py` 的 `PINMAP` |

| 电气要求（上拉/分压/限流/滤波） | `电气连接规范.md` §4（同时改图上脚注） |
| 电源电路的器件与数值 | `01 电源与保护.tex`（手写；注意文件头的**版面约定**，支路不许越到下方母线的 x 区间） |

```bash
python "生成接线图.py" --build    # 重新生成全部图 + 接线表 + netlist.json（需 MiKTeX + poppler）
python 自检.py                    # 三遍检验，退出码必须为 0
```

> 脚本在 **ASCII 临时目录**里编译（Windows 中文路径下 `xelatex`/`pdftoppm` 不稳），再把 `pdf`/`png` 拷回本目录。

## 四、v3.0 相对前两版的变化

| 变化 | 原因 / 来源 |
|---|---|
| 灰度主方案 = **感为（I2C1）**，亚博降备用，两座均为 **16P 排母** | v0.2（v1.0 写 4P/6P，实物插不上） |
| **I2C1 上拉 5V**（模块板载跳帽不插，PCB 10k 到 5V） | **感为手册**："外置上拉源不得低于 72% 供电电压"（=3.6V）→ 3.3V 不达标 |
| **OLED / MPU6050 独立 I2C2（3.3V 上拉）** | 5V 上拉会打坏 3.3V 器件（v1.0 遗漏整条支路） |
| **遥测留在 USART1（PA9/PA10）**，BLE 走 USART2 | 与已冻结的 `docs/遥测协议.md`、已跑通的 MVP1、`tools/*.py` 一致 |
| 编码器 = **TIM4（左）/ TIM3（右）**，不用 TIM2 remap | 避开 TIM2 Full Remap 与 USART2 抢 PA2/PA3；核心功能不依赖关 JTAG |
| PWM = **TIM1_CH1/CH4（PA8/PA11）** | PA11 只作输出，正好给 PWM；TB6612 方向改 PB0/PB1/PB12/PB13 |
| 电压采样回到 **PA0** | 上述调整后 PA0 空出 |
| **编码器 VCC 走 +5V** | 王政淋实测旧板 |
| **电机 6P 针序 = M1/GND/C2/C1/VCC/M2** | 王政淋实测（v0.2 那条是猜的，错的） |
| **保险丝 T3A 预留 + AO4407A 反接保护**，保险丝放最前 | 王政淋选型与排序（比"2A＋IRF9540/AO3401"更合适） |
| **PB2（BOOT1）标为保留勿接** | v3.0 新增：复位时被拉高会从 SRAM 启动 → "固件不跑"的假故障 |
| BLE 按**实物 6P** 做封装；VCC 取 3V3 | 王政淋实测（v0.2 误按 HC-06 4P） |
| 新增 `自检.py`（三遍检验） | v3.0 新增：交付前可执行验证 |
