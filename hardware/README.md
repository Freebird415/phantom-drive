# hardware —— 电路与电气集成

电路设计文件：嘉立创 EDA 工程、原理图/PCB 导出、BOM、接线图、点亮验证记录。

- 相关任务：H01 选型与采购 · H02 电路与电气集成
- 主要使用者：王政淋（H01 · H02）；熊雅琦配合元件核对与原理图评审（S01）

## 要求（红线）

| 要求 | 依据 / 说明 |
|---|---|
| **单电源** | 比赛规则原文：小车只能使用一个随车装载的电源；多电源不符合规定 |
| 电源架构 | 12V 锂电池 → TB6612 直供电机；降压模块（MP1584 / 5V-3.3V）供 MCU 与外设 |
| 保护 | 必须装**总开关 + 保险丝**；上电前检查极性与短路 |
| 连接规范（成品接口） | 电池/大电流 → XT30 / XT60 / T 插；电机动力线 → 焊接 或 XH2.54 / JST-VH；信号线 → XH2.54 / PH2.0 带扣插口（板端用座子）；不拆装的连接 → 焊死；**杜邦线仅限调试与 SWD** |
| 布线唯一依据 | **《引脚分配表》**（第 3 周末冻结）；冻结后改动需李沛阳、王政淋双方确认 |
| PCB 平台 | 嘉立创 EDA；预留标准插口、大电流焊盘、SWD、备用 IO、保险丝、电压检测分压 |
| 避障传感器选型 | 要求受光影响小（候选超声波 / ToF），由 H01 定案 |
| **止损线** | 第 6 周 PCB 未点亮 → 回退洞洞板方案，不占关键路径 |
