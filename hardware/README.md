## 电气架构

单 12V 锂电池 → TB6612 直供电机；MP1584 → 5V（灰度、超声波、编码器、蜂鸣器）；5V → 3.3V 供 MCU 与外设。

## 红线

| 项 | 要求 |
|---|---|
| 单电源 | 规则要求车上只有一个电源 |
| 总开关 | 必须有；板上无保险丝/反接保护 ⇒ 上电前核极性与短路 |
| 连接件 | 电池/大电流 XT30/XT60/T 插；电机线焊接或 XH2.54/VH；信号线 XH2.54/PH2.0 带扣；杜邦线仅限调试与 SWD |
| 引脚 | 以 `docs/引脚分配表.md`（v3.0，已冻结）为准；接线记录以 `电气设计/完整接线.md` 为准 |
| 超声波 Echo | 5V 输出，必须分压（2k+1k+2k = 3.0V） |
