## 二、硬规则（违反即算错误输出）

1. **不得自行发明引脚**。`netlist.json:pinmap` 之外的功能，视为"不存在"。
2. **不可用引脚**：`PC14`、`PC15`（板上 32.768kHz 晶振）、`PD0`、`PD1`（板上 8MHz 晶振）。`PA11`/`PA12` 只可作输出（PA12 上有 1.5k 上拉）。
3. **两条 I2C 绝不并联**：I2C1（PB8/PB9）上拉到 **5V**，只挂灰度；I2C2（PB10/PB11）上拉到 **3.3V**，只挂 OLED + MPU6050。并联会烧 3.3V 器件。
4. **核心板 5V 脚与 3V3 脚只能接一个**（本项目接 5V），本板**不得**再产生 3.3V。
5. 灰度**两个独立座**（感为针 1=GND、亚博针 1=5V，反相）；超声波**两个 Trig 独立**；Echo 必须分压。
6. 电机大电流**不走排针**；保险丝 **3A 慢断** + P-MOS 反接保护不得省。
7. **改数据要改源头**：`netlist.json` / `接线表.md` / PDF / PNG 都是 `原理图草案/生成接线图.py` 的产物，**不要手改**；改脚本顶部 `PINMAP` / `FIGS` 后重跑 `python 生成接线图.py --build`。
8. **提交前先拉取、提交需用户确认**：`git pull` → 改 → 汇报 → 用户说"提交"才提交（根目录 `AGENTS.md` 硬规则 2）。
9. **不要动规范文件**：`AGENTS.md`、`说明书.md`、`README.md`（根目录）、`docs/`、两个 `.bat`（组员身份下）。

## 三、落图工作流（建议）

```
1. 读 netlist.json + 电气连接规范.md（§3~§6 定"接什么"，§4/§8 定"怎么接"）
2. 核对 BOM 资料索引里各器件手册的关键参数（§7 表末列了"待复核"项）
3. 在嘉立创 EDA 建工程 → 放核心板排母 → 按 §6 接口清单建连接器
4. 逐条落 netlist.nets；每落一条，对照 §10 自检清单
5. 所有接口做"带扣座 + 并排排针"双份；补测试点 TP
6. 输出：原理图 PDF + Gerber + BOM + 网表 → 交李沛阳核对与引脚契约是否一致
```
