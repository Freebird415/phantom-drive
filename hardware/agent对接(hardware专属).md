## 二、💥 本次对接差错复盘（2026-09-20，**照着避免重犯**）

上一轮王政淋 agent 产出的《PCB 设计交接说明》有 4 处与既有事实冲突，根因与对策如下。**这 4 条已写进红线，不得再犯。**

| # | 出了什么错 | 根因 | 为什么**不能**这么改 | 现在的正确做法 |
|---|---|---|---|---|
| 1 | **串口对调**：把 USB-TTL 遥测放到 USART2，BLE 放到 USART1 | 遥测口的约束只写在 `docs/遥测协议.md` 和 `firmware/README.md`——**硬件侧看不到** | `docs/遥测协议.md` 物理层写死 USART1；P01 的 MVP1 已按此**实机跑通**；`tools/run.py`、`telemetry.py` 全按 USART1 写；改串口号 = 改协议 + 改固件 + 改上位机 + 三份文档 | **遥测固定 USART1（PA9/PA10）；BLE 走 USART2（PA2/PA3）**（见 决策登记 E-04/E-05） |
| 2 | **感为 I2C 上拉写成 3.3V** | 只看"3.3V 器件用 3.3V 上拉"的经验，**没读感为手册** | 感为手册原文："如果外置上拉源，灰度传感器要求**总线最低上拉源为 72% 的供电电压**，低于此阈值**通讯极易失败**" → 72%×5V=**3.6V**，3.3V 不达标 | **I2C1 上拉 5V（10k）**；感为板载 5V 上拉跳帽**不插**（避免两处上拉并联） |
| 3 | **OLED 与 MPU6050 整条支路消失** | 只在对话里说过"全装"，**没落进仓库** | 用户明确要求全装；且若后来顺手挂到灰度那条 5V 上拉的 I2C1 上，**SSD1306 / MPU6050 会被 5V 打坏**（极限约 VDD+0.3=3.6V） | **独立 I2C2（PB10/PB11），上拉 3.3V，与 I2C1 永不并联**（决策登记 E-03）；**OLED 2026-10-10 放弃 ⇒ I2C2 只剩 MPU6050** |
| 4 | **灰度接口按 4P / 6P 画** | 沿用了亚博**老型号**教程的 6P 说法，**没看实物照片** | 实物：感为与亚博**都是 1×16P / 2.54mm 排针**，只是我们从里面挑 4 根用；画 4P 座模块插不上 | **两个 16P 排母，各一个座**；感为 1=GND、2=+5V，亚博 1=5V、2=GND（**针 1/2 相反，不能共用**） |

**共性教训**：这 4 条都不是"不会画电路"，而是**信息源不在必读范围内 / 只存在于对话里**。所以本文件的第一节把必读清单和跨域约束都列了出来——**先读，再动手**。

## 三、硬规则（违反即错误输出）

1. **不得自行发明引脚**：`netlist.json:pinmap` 之外的功能视为"不存在"。
2. **不可用引脚**：`PC14`/`PC15`（32.768kHz 晶振）、`PD0`/`PD1`（8MHz 晶振）、`PB2`（BOOT1，**禁止接任何会拉高的信号**）；`PA11` **只可作输出**（`PA12` 作输入用：按键，核心板已带 1.5k 上拉）。
3. **两条 I2C 绝不并联**：I2C1（PB8/PB9）上拉 **5V**，只挂灰度；I2C2（PB10/PB11）上拉 **3.3V**，只挂 MPU6050（OLED 已放弃）。
4. **核心板 `5V` 脚与 `3V3` 脚只能接一个**（本项目接 5V）；本板**不得**自己产生 3.3V。
5. **不用 TIM2、不设任何 remap**（Full Remap 会与 USART2 抢 PA2/PA3）。
6. 灰度**两个独立 16P 座**；超声波**两个 Trig 独立**；Echo 必须分压。
7. 电机大电流**不走排针**；保护顺序 **保险丝(T3A) → AO4407A 反接保护 → 总开关**，不得省。
8. **改数据要改源头**：`netlist.json` / `接线表.md` / PDF / PNG 都是 `电气设计/生成接线图.py` 的产物，**不要手改**；改脚本顶部 `PINMAP`/`FIGS` 后重跑。
9. **交付前必须跑自检**：`python hardware/电气设计/自检.py`，**退出码必须为 0**；非 0 不许交付。
10. **提交前先拉取、提交需用户确认**（根目录 `AGENTS.md` 硬规则 2）；规范文件（`AGENTS.md`、`说明书.md`、根 `README.md`、`docs/`、`.bat` 脚本）组员不要动。

## 四、落图工作流（建议）

```
1. 读 ../项目记录/决策登记.md          ← 先知道哪些已经定了
2. 读 电气设计/电气连接规范.md（§3 定"接什么"，§4/§8 定"怎么接"，§9 定"能不能改"）
3. 读 电气设计/netlist.json            ← 逐条抄，不要凭记忆
4. 核对 BOM 资料索引里各器件手册的关键参数（规范 §7 末尾列了"待复核"项）
5. 在嘉立创 EDA 建工程 → 放核心板排母 → 按 规范 §6 建连接器
6. 逐条落 netlist.nets；每落一条对照 规范 §10 自检清单
7. 所有接口做"带扣座 + 并排排针"双份；补四个电源域的测试点 TP
8. 跑 python hardware/电气设计/自检.py（退出码 0）
9. 输出：原理图 PDF + Gerber + BOM + 网表，回传审核
```
