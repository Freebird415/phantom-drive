# 练习 05 · 综合练习与对照表

## 任务：完整走一遍

1. `拉取.bat` → 同步
2. 在本文末尾加一行：`<你的名字> 已完成全部练习`
3. `提交.bat` → 选类型 → 写描述 → 上传
4. 打开 GitHub 网页，确认你的提交出现在历史里

## 常见情况对照表

| `[1/4]` 里看到 | 含义 |
|---|---|
| ` M 文件名` | 你**修改**了已有文件 |
| `?? 文件名` | **新增**的文件 |
| ` D 文件名` | **删除**了文件（会同步删除） |
| 「没有检测到任何改动」 | 你还没改东西，或者已经提交过了 |
| 「上传被拒绝…正在自动合并」 | 别人也提交了，脚本会自动合并后再上传，等它跑完即可 |
