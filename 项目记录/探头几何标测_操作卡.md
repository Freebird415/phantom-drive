# 15° 探头几何标测 · 操作卡（给毕烨恺 · 一人可独立完成）

> **目的**：把 A02 现在用的"名义探头几何"换成**实测值**。不需要 AI、不需要改代码、不需要 git。
> **要拿到 4 个数**：①左右探头**首次看到障碍**的距离 ②**最近**能测到多近 ③**正前方/侧向覆盖**（有没有盲区）
> ④**探头前端→车最前端**的偏移（这条也可以从日志反算，见 §5-D）
> **总时长**：必做 8 条 ≈ **15 分钟**；加强 4 条 ≈ +8 分钟；兜底 4 条 ≈ +6 分钟。
> **工具**：`蓝牙日志.bat`（网页界面）+ 卷尺 + 纸笔 + 手机（拍照）。
> **相关**：`firmware/文档/驱动接口说明.md` §A02（探头几何）· `项目记录/决策登记.md` E-31

## 0. 一页看明白

**每条日志都是一次独立的「开始接收 → 摆一个位置/推一遍 → 停止接收」**，一条只对应一件事。
⇒ **哪一条做错/没录上都不要紧**：只重做那一条，其他不受影响；**我会自动把不对的那条丢掉**（见 §8）。

要做的事只有三种"动作"，都在 §3~§5 里写清：

| 动作 | 怎么做 | 用在哪 |
|---|---|---|
| **推近** | 从远往近，每进 100mm（或 50mm）**停 3 秒** | A1/A3/B1/B3/B4/B5 |
| **推远** | 同上但方向反过来（从近往远） | A2/B2（**反向复核，专门用来兜错**） |
| **定点** | 摆好**不动**，静止 8~10 秒 | 0/C1/C4/C5/E1/E2 |

**每条日志里，"停 3 秒"就是在屏幕上留下一段"平台"**（数字不跳的一段）。平台 = 我的标尺：
我按平台顺序就能知道障碍物当时在哪个刻度，**不用你按关键帧、不用你报位置**。

## 1. 准备（摆好后不要动车）

1. 车**静置**在直线段上（桌面或赛道直线都行），**车头朝前**，全程别碰车；上电，3V3 ≈ 3.3V。
2. 电脑双击「蓝牙日志.bat」→ 等状态栏显示 **蓝牙已连接 + 有帧率**。
3. 卷尺沿**车头前进方向**铺开，**0 刻度对齐「车最前端」**；铺好后**别再碰卷尺**。
4. 障碍物：**60×60×150（阿凡提）**、**150×100×150（莫高窟）**；没有实物就用**立起来的厚书**
   （实心、够高：至少与探头同高，最好 150mm）。
5. 纸 + 笔（记录表照抄 §6）；手机放旁边（每条开工前拍一张，见 §7）。
6. **左右的定义**：沿车前进方向看，左手边 = **左探头那一侧**，右手边 = 右。

## 2. 一条日志的标准动作（每次照做，5 步）

```
① 点「开始接收」        ⚠️ 不要点「监测」——监测不落盘，等于白做
② 把障碍物摆到"起点刻度"，停 3 秒          ← 让屏幕先出现一个平台
③ 按 §3~§5 的动作走，每到一个刻度停 3 秒
④ 走到"结束刻度"，停 3 秒
⑤ 点「停止接收」→ 纸上记：本条 = 开始时间（时:分）＋ 编号
```

**三条纪律（违背了那条日志就作废）**

- 摆好后 **手拿开、人退到车的侧后方** —— 手/身体留在探头前面或两侧 15° 锥里，读数会乱跳（±18cm）。
- **不碰卷尺** —— 一碰，X 全部作废。
- **每条都要记「开始时间」** —— 日志文件夹名就是 `<日期>_<时:分>`，靠它对号（时间忘了 ⇒ 这条作废重做，宁重做别猜）。

**屏幕读数含义**（超声波那两列，左列=左探头）

| 显示 | 含义 |
|---|---|
| **数字（mm）** | 测到了 ✓ |
| `-1` / `-2` | 没测到（**正常**：说明障碍物还没进锥） |
| `-6` | 被限流跳过（**正常**，不用管） |
| `-5` | 太近（<20mm）或太远（>4000mm） |

## 3. 必做：8 条（**只做这 8 条也够我算出全部 4 个数**）

### 【0】基线 · 无遮挡
- **摆哪**：先把车周围清空（人和障碍都拿开）。
- **怎么动**：不动，静止 **10 秒**。
- **屏幕长什么样**：两列全是没有数字（`-1`/`-2`）。
- **纸上记**：开始时间；若**出现了数字**写下来（说明周围有会反射的东西，先记着别动场地）。

### 【A1】右侧 · 60mm 障碍 · **推近**
- **摆哪**：障碍物**内边贴黑线外沿**（车压线正中时 = 离车中轴 **10mm**），摆在**右侧**；起点 **X=1200**。
- **怎么动**：每次往近推 **100mm** 停 3 秒 → 推到 **X=200** 停 3 秒 → 停止接收。
- **屏幕长什么样**：**正常 11 个平台**；前几个平台没数字，中间某个平台开始出数字，后面一直有。
- **纸上记**：开始时间 ＋ "**第一次出数字**"时的卷尺读数（大约几 mm 就行）。

### 【A2】右侧 · 60mm 障碍 · **推远**（反向复核，专门用来兜错）
- **摆哪**：同 A1，但**起点是 X=200**（贴着车近处）。
- **怎么动**：每次往**远**推 **100mm** 停 3 秒 → 推到 **X=1200** 停 3 秒 → 停止接收。
- **屏幕长什么样**：与 A1 相反——**开始有数字，推到某处突然没有**；平台数同样 11 个。
- **纸上记**：开始时间 ＋ "**最后一次有数字**"时的卷尺读数。

### 【B1】左侧 · 60mm 障碍 · **推近**
- **摆哪**：**左侧**、内边贴线外沿（离车中轴 10mm）；起点 **X=1200**。
- **怎么动 / 屏幕 / 记什么**：与 A1 完全一样（只是换到左边）。

### 【B2】左侧 · 60mm 障碍 · **推远**
- **摆哪/怎么动/记什么**：与 A2 完全一样（换成左侧）。

### 【C1】正前方中央 · 定点（**验"有没有中央盲区"**）
- **摆哪**：障碍物**中心对准车中轴**（Y=0），**X=400** 不动。
- **怎么动**：静止 **10 秒**。
- **屏幕长什么样**：**应该有数字**（15° 改装的目的就是消掉正前盲区）。
- **纸上记**：开始时间 ＋ 写两个字：**读到了 / 没读到**。

### 【C2】X=400 · 障碍从车中轴**缓慢右移**
- **摆哪**：起点 = 障碍中心在车中轴（Y=0），X 固定 **400**。
- **怎么动**：**慢慢往右移**（约 5 秒移动 250mm），**中途不要停**。
- **屏幕长什么样**：开始有数字 → 移到某个位置**数字消失**。
- **纸上记**：开始时间 ＋ "**数字消失**时横向移了大约多少 mm"。

### 【C3】X=400 · 障碍从车中轴**缓慢左移**
- **摆哪/怎么动/记什么**：与 C2 完全一样，只是**往左**移。

> ⭐ **只做完这 8 条**：A1+A2 给"右侧首次检出"，B1+B2 给"左侧"（两条互相复核），C1+C2+C3 给"覆盖/盲区"；"最近可测距离"从 A1/A2 尾段（X=200 那一端）读出来。

## 4. 加强：4 条（**强烈建议做，把精度和容错都提一档**）

| 编号 | 做什么 | 与必做哪里不同 | 纸上记 |
|---|---|---|---|
| **A3** | 右侧 60mm、**50mm 步**细扫：在 A1"首次出数字"的位置 **±150mm** 范围内，每 **50mm** 停 3 秒 | 步长更细 ⇒ 首次检出距离精度到 ±25mm | 开始时间 ＋ 第 1 个出数字的刻度 |
| **B3** | 左侧 60mm、**50mm 步**细扫（同 A3，换左侧） | 同上 | 同上 |
| **B4** | **右侧 · 150×100 大障碍** · 推近：X **1200→300**，每 100mm 停 3 秒 | 验"障碍越宽越早看到"（正常 10 个平台） | 第一次出数字的刻度 |
| **B5** | **左侧 · 150×100 大障碍** · 推近（同 B4，换左侧） | 同上 | 同上 |

> 为什么值得做：**大障碍（B4/B5）与小障碍（A1/B1）两条曲线一交叉，就能反推出探头的方位角覆盖**，
> 不用依赖我们推算的"各覆盖 0°~30°"。而且大障碍就算 A/B 系列全废，也能单独给出首检距离。

| 编号 | 做什么 | 用途 |
|---|---|---|
| **E1** | 右侧 60mm，障碍**内边距车最前端 100mm**，定点静止 8 秒 | "最近能测到多近"的独立证据 |
| **E2** | 右侧 60mm，障碍**内边距车最前端 50mm**，定点静止 8 秒 | 同上（更近一档） |

| **D** | 卷尺量：①探头前端→车最前端 = ? mm ②探头离地高度 = ? mm | ④ 偏移；**忘了量也没关系，我能从 A/B 的日志里反算** |

## 9. 出错了怎么办（**这就是本卡容错的地方**）

| 情况 | 怎么办 | 后果 |
|---|---|---|
| 某条没录上 / 摆错 / 多推了一步 / 忘了记时间 | **只重做那一条**（`停止接收 → 开始接收 → 重做`） | 只损失那一条，**其他照旧可用** |
| 先点了「开始接收」又点了一次 | 第二次会被忽略（要先停止）⇒ 检查屏幕是否真在记录 | 那条作废重做 |
| 用了「监测」而不是「开始接收」 | 停止 → 重新「开始接收」 | 那条作废重做 |
| 卷尺被碰动 | 那一条作废重做 | 其他条不受影响 |
| 手/身体进了探头前面 | 那一段数据不用（我会只看稳定平台） | 通常不用重做 |
| 蓝牙掉了 | 等重连后**从当前刻度**重开一条 | 前一条能用就用，缺的那段由反向那条兜住 |

**为什么错几条也不怕（我的容错设计）**

1. **每个目标都有 ≥2 条独立日志**：右侧首检 = A1 + A2 + A3；左侧 = B1 + B2 + B3；覆盖 = C1 + C2 + C3 + C4/C5；最近距离 = A1/A2 尾段 + E1/E2。
2. **推近和推远是两条**：万一一遍中途走了神，另一边是独立测量。
3. **每条日志的"形态"都不一样**（平台数 11 / 11反向 / 7 / 10 / 单平台 / 无平台）
   ⇒ 就算你把编号或时间写错，我也能从数据长相判断"这其实是哪条"，**记错号不会毁掉数据**。
4. **照片**兜住"摆放/刻度记错"这一类错误。

## 10. 最容易犯的五个错

1. 点了「**监测**」而不是「开始接收」（监测不落盘）。
2. 没先「停止接收」就点「开始接收」（第二次会被忽略 ⇒ 白做）。
3. 手 / 身体留在探头前面或两侧 15° 锥里（读数乱跳 ±18cm）。
4. 碰到卷尺（X 全部作废 ⇒ 那条重做）。
5. 纸上没记开始时间（对不上号 ⇒ 只能重做）。

## 11. 术语

| 词 | 意思 |
|---|---|
| **车最前端** | 卷尺 0 刻度对齐的那一点（不是探头面），X 全部从这里量 |
| **车中轴** | 车体左右对称的中线；Y 从这里量，右为正 |
| **贴线边** | 障碍物靠车中轴那一侧的**边**与黑线外沿相齐（不压线）；车没压线时直接量到车中轴 |
| **平台** | 屏幕读数稳定不动的一段时间（因为你停了 3 秒）——我的"刻度标尺" |
| **首次出数字** | 从远往近推时，**第一次**出现有效距离的那一点 |
