## 0. 合规红线（违反直接不予参赛 / 不得分）

| 规则原文 | 对我们的意思 |
|---|---|
| "比赛时，小车启动后必须实现全自动运行，过程中**不得进行任何人工干预**，如遥控操作或通过手机、电脑等设备进行远程控制。凡违反此规定的小车将不予参赛。" | ⚠️ **无线链路只能"收日志"，绝不能发控制命令**。跑车时 `BTL 1` 是车自己开的（发车按键里自带）；**发车后不许用电脑/BLE 发任何命令** ✗ |
| "小车**尺寸 ≤ 250mm╳200mm╳200mm**，尺寸不符合将扣每轮成绩 10%" | 赛前量一次（含电池/线） |
| "小车**只能使用一个随小车装载的电源**（即装在小车内部）" | 不带外接电源上赛道 |
| "赛道不允许另外增加任何标记或者在赛道周围增加补光或者遮光" | 别往赛道上贴东西；补光/遮光只能装在**小车上** |
| "若发生非避障**脱离**循迹线…脱离期间所经赛段不计分"（脱离：整体外轮廓垂直投影与黑线**无任何交集**） | 丢线即失分 ⇒ 宁可慢、别丢线 |
| "一旦**逆行**，本轮比赛结束" | 起步前确认车头朝向正确 |
| "若小车**所有轮子全部离开广告布**，则本轮比赛结束" | 别冲出布边 |
| "**交卡后立即开始该次比赛，不得再调试**"；除负责启动的同学外其他人退出赛道 | 交卡前必须全部就绪（含 BLE 已连上）✗ 之后再改任何东西 |

## 1. 发车（起始位置）

> 规则原文：**"起始位置：循迹避障小车最前端投影线对齐起始线，小车自动按循迹前进。"**
> 计时："小车通过起始线，计时开始" · "起始线和终点线两侧有**计时光电门**，调试过程应考虑其影响"

### 1.1 我们的发车动作（唯一推荐）

| 步骤 | 做什么 | 现象 |
|---|---|---|
| ① | 车放好：**最前端投影线对齐起始线**（对齐，别压过去） | — |
| ② | 确认朝向正确、车在布内、线在传感器正下方 | 灰度能看到线 |
| ③ | **长按 PA12 按键 1 秒** | **1 声短鸣** = 已发车 ✓ |
| ④ | 手拿开，**全程不再碰车** | 车自动循迹前进 |

**车摆在起始线 T 头【前面】是很正常的**（此时八路全 0）——
固件有**起步找线**（2026-10-01 新增，**尚待场地验证**）：发车后会**慢速直行**去找线，压过 T 头（日志会发 `$E 83 START T ignored`）
后碰到正常黑线就自动转正常循迹（灰度状态 0 → 5 → 1 ✓）。**3 秒**还没找到线才停车（安全兜底）。

**这一按同时做了 5 件事**（都在固件里，不需要电脑）：
0. `Trace_StartRun()` 打开**起步找线**（关键：否则全白会当场停车 ✗）
1. 复位精停状态（准备新一趟）
2. `Log_Start()` 开始记录（接着上次的帧号，不覆盖）
3. `Log_SetBle(1)` **自动打开无线回传**（跑车时插不了串口 ✓）
4. `Trace_SetDrive(1)` 真的给电机发车

### 1.2 声音对照表（场地没屏幕，全靠听）

| 声音 | 含义 |
|---|---|
| **1 声短鸣** | 已发车 ✓（长按 1 秒）。蜂鸣器**默认不静音**（v5 起，2026-10-01 实机确认 ✓）；若听不到先发 `MUTE 0` 检查 |
| **2 声长鸣** | 到终点、已刹车停（自动） |
| **3 声短鸣** | 手动停车 + 停止记录（再长按 1 秒） |

### 1.3 台面等效命令（**只用于插线调试，赛场上不要用**）

```
TRACE 1        # 发车（给电机使能）
SNAP 1         # 开始记录（板载快照 100Hz）
BTL 1          # 开无线回传
TRACE 0        # 停车（只停电机，不停止记录）
STOPDIST 80    # 设精停最后一段距离（mm）
FINSTAT        # 看精停状态
FINRESET       # 复位精停状态（准备新一趟）
```

## 2. 终点与停止

> 规则原文：**"终点位置：循迹避障小车过终点线，计时终止，本轮比赛结束。"**
> **停止分**："小车通过终点线，计时停止；且**小车停止时，小车投影最末端不超过终点线**，则获得 20 分，否则不得分。"

⇒ **不是"停得越远越好"** —— 停晚了尾巴过线就丢 20 分 ✗

### 2.1 固件现在的逻辑

```
8 路灰度【全黑】连续 3 帧 **且已武装**（先在线上连续跑够 1.5 秒，
否则**起点的 T 头也会被当成终点** ✗）
        ↓
进入"走最后一段"：按编码器走 STOPDIST 毫米（默认 80mm）
        ├─ 走够 → 刹车停 + 2 声长鸣 + 自动存 Flash
        └─ 3 秒还没走够（轮子堵转/打滑/离地）→ 也刹车停（超时兜底）
```

### 2.2 ⚠️ 现场必须实测的两件事（直接决定这 20 分）

| # | 要测什么 | 为什么 |
|---|---|---|
| ① | **终点线（20mm 宽黑线）/ 赛道完成标识（120×50×120mm 3D 打印件）到底哪个会让"8 路全黑"？** | 我们的触发条件是"8 路同时看到黑"。**20mm 宽的黑线很可能只压到 1~2 路** ✗ ⇒ 若终点只有那条线，现在的逻辑**根本不会触发** |
| ② | **触发点（全黑那一刻）到"车尾不出线"的允许前进距离是多少？** | 车长约 200mm ⇒ 允许距离 ≈ 车长 − 车头到传感器的距离。据此设 `STOPDIST <实测值>` |

**现场动作**：把车摆到终点线上，用 `GR`（或 BLE 日志窗口里的灰度小灯）看**到底几路黑**；
再量"传感器 → 车尾"的距离，留 20~30mm 余量设 `STOPDIST`。

## 3. 收尾（每轮结束后）

| 步骤 | 动作 | 说明 |
|---|---|---|
| ① | **长按 1 秒** | 3 声短鸣 = 停车 + 停止记录（**自动存 Flash，掉电不丢**） |
| ② | 拿回电脑/台面：插线 → `DUMP` | 读板载快照（100Hz 全精度），或用「蓝牙日志.bat」收的 CSV |
| ③ | 记录这一轮的：`STOPDIST` / 参数 / 现象 | 写进 `项目记录/实际进度.md` |

> ⚠️ **先停车再断电**：停车会自动存 Flash；断电前没停车就可能丢这一轮数据。

## 4. 赛前 60 秒检查清单

- [ ] 尺寸 ≤ 250×200×200（含电池、线）
- [ ] 只有一个车载电源；电池电量够（一轮最长 **5 分钟**，超时本轮结束）
- [ ] 灰度在线（`TRACE 0` 回包的"灰度=在线"）；**陀螺仪在报数**（仪表盘 gz 不为 0；不报就发 `MPUINIT`）
- [ ] 参数是本轮要用的（`GET` 看 kp/ki/kd/base）
- [ ] `STOPDIST` 已按现场实测设好
- [ ] 蓝牙日志窗口已连上、状态栏有帧率（**交卡后不能再调** ✗）
- [ ] 车放在起始线：**最前端投影对齐起始线**
- [ ] 长按发车 → 听到 1 声短鸣 → 手拿开

## 5. 常见异常对照

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 长按没声音、车不动 | 按键没按住 1 秒 / 上电不足 2 秒（固件前 2 秒不响应）/ `TRACE` 已被关 | 重新长按；确认上电 > 2 秒 |
| 车一动就停 | 灰度离线（`allow_drive=0`）或丢线 | 看 `TRACE 0` 的"灰度="；把车放回线上 |
| 跑着跑着左右猛打舵 | 灰度离线时会被 `$E 92/93` 报出来 | 停车检查灰度供电/高度 |
| 到终点不停 | 触发条件没满足（见 §2.2）；或过早的全黑被当成起始 T 头忽略了（`$E 83`）| 看日志有没有 `$E 80 FINISH LINE`；`FINSTAT` 看状态 |
| 起步不动 | 起步找线 3 秒超时，或按住不足 1 秒 | 重新长按；确认车头正对起始线 |
| 终点到了但冲太远 | `STOPDIST` 偏大 | 调小 `STOPDIST` |
| 陀螺仪 gz 一直 0 | MPU6050 复位回睡眠（固件会自愈，约 1 秒） | 等 1~2 秒；仍 0 就发 `MPUINIT`；再看 `MPU` |
