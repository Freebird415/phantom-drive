## 2. 评分规则要点

**总分构成**：现场比赛 80%（比赛分 80% + 车架制作分 20%）+ 现场演讲 10% + 组员互评 10%

**比赛得分 X =（赛段分 40 + 避障分 40 + 时间分 40 + 停止分 20）×（1 − n×10%）**

- **赛段分**：4 段各 10 分，车最前端通过赛段标识最前端即得该段
- **避障分**：每成功避一障 10 分；与障碍物任何接触/撞开/撞移即失败；障碍物从车底穿过不算
- **时间分** = 40 × t₁/t₂（t₁ 为全场最快队用时）→ 速度直接换分
- **停止分**：过终点线且**车尾投影不超过终点线**（精停），20 分
- **不合格项 n**（每项每轮 −10%）：尺寸超标、非单电源；车架非自制、非全自动 → 直接取消资格

**硬性要求**：尺寸 ≤250×200×200mm；车架自制（主结构 + 中心设备加工 + 留证据）；全自动运行；车上一块电源；允许车载补光/遮光；场地不可加标记。

**现场演讲**（5 分钟 + 3 分钟问答）四维度：项目内容 25 / 技术创新与难点 25 / **小车成本 25** / 报告演讲 25。

**报销**：额度 200 元；抬头「华南理工大学」税号 12100000455414429R；玩具类与无关发票不报；发票 ≤20 张（同店集中开一张）；商品拍照存档并填表；报销周期半年至一年。

## 4. 技术方案（已定部分）

### 4.1 整车构型
- **三轮构型**：双 JGB37-520 减速电机（12V 333RPM）+ 1 万向轮，差速转向
- 车架自制，尺寸严控 ≤250×200×200mm；加工方式 = **板材激光切割 + 3D 打印件**，用中心设备并全程留证（`mech/加工证据/`）
- 旧车（双轮平衡车）仅作参考与拆件取材，车架必须重新设计

### 4.2 电气架构
- **单电源**：1×12V 2200mAh 锂电池 → TB6612 直供电机；降压模块（MP1584 / 5V-3.3V）供 MCU 与外设
- 保护：总开关 + 保险丝
- **成品连接规范（已拍板）**：
  - 电池/大电流 → XT30 / XT60 / T 插
  - 电机动力线 → 焊接 或 XH2.54 / JST-VH
  - 信号线 → XH2.54 / PH2.0 带扣插口（板端用座子）
  - 不拆装连接 → 直接焊死
  - 杜邦线仅用于调试阶段与 SWD 烧录口
- PCB：嘉立创 EDA 设计（预留标准插口、大电流焊盘、SWD、备用 IO、保险丝、电压检测分压）；**现用版 v2.1 已到货装车、电器功能验收正常（10/10）**

### 4.3 传感与控制
- 循迹：八路灰度传感器——**感为科技（主选，I2C，可读数字量+模拟量）+ 亚博智能 YB-MUX04（备用，独立 16P 座）**，两套均已有
- 避障传感器：**HC-SR04 超声波 ×2（左右各 1）**（9/20 定案；两模块必须分时触发，避免互相串扰）
- 编码器：JGB37-520 为**带编码器版本**（6 线）；**确认用于闭环测速**，接入 TIM4（左）/TIM3（右）编码器模式；电机侧用现成 JST-XH 6P 座（针序实测 **M1/GND/C2/C1/VCC/M2**，编码器 VCC 走 +5V）
- 人机：蜂鸣器（丢线/撞障提示）、用户按键、12V 电源指示灯（均装）
- 控制：PID 循迹 + 避障状态机（检测判侧 → 绕行 → 短距回线 → 终点精停）
- MPU6050：A02 试跑版使用缓存的签名偏航率估姿/局部曲率；零偏、安装方向与名义距离尺度须复核，A01 保持原代码
- A02 v4 试跑参数（反馈故障未修复，非稳定版）：名义车半宽 100mm、轴前 40mm/轴后 170mm（模型 200×195.5×100mm，朝驱动轮端前进）；车身余量目标 25mm加8mm跟踪预算，**不是已测障碍间隙**。编码器名义目标速度：外移/越障 80mm/s、回程/搜线 60mm/s、边缘捕线 40mm/s、中心跟随 50mm/s；进入前沿用 A01 速度。按估速和转向空间动态提前（135mm/s 示例约 395mm 探头读数），仅累计新鲜双次同侧回波；空间不足则停车，30mm 仍只作极近兜底。
- 回线验收：沿障碍边平行通过、长车尾扫掠区越障后平滑回归；连续局部中心 350ms 且线误差变化/角速度受限才交接。搜线 750mm/13s、居中 250mm/4.5s、整次 1800mm/30s 均为名义上限；已见线又丢线 150ms/25mm 截止。**当前先恢复有效转向反馈并补异常保护；完全离线后出现的新弯道不可由旧曲率推知，失败不能继续盲开。**

### 4.4 开发与调试链路（Vibedebug 地基）
- 工具链：PlatformIO / arm-none-eabi-gcc + ST-Link（命令行编译与烧录）
- 遥测：串口输出传感器原始值 / PID 中间量 / 状态机状态 / 事件打点；Python 脚本落盘 CSV + 绘图；在线调参
- 目标闭环："跑一趟 → 读数据 → 描述现象 → agent 改代码/参数 → 烧录 → 再跑"
- 交付分级：MVP1 一键烧录+串口日志（**9/13 已完成**）→ MVP2 传感器数据落盘绘图（9/30，面包板 demo 上先做）→ MVP3 PID/状态机 + 在线调参（**10/12**）

### 4.6 固件结构与算法代码缝（2026-09-30 定）
- 分层：`bsp/`（板级）← `drv/`（器件驱动）← `app/`（应用层）；依赖只允许 **app → drv → bsp**
- **算法代码缝**：A01 只写 `app/app_trace.c`、A02 只写 `app/app_avoid.c`（每人一个文件，等于传统工程里的 `main.c`）；
  算法层只调 `drv_*`；**仲裁由 `main.c` 负责**（避障接管时循迹"只算不发"，防 100Hz 冲掉避障命令）
- **发车开关默认关**（`TRACE 0`/`AVOID 0`）：只算不发，但 `$T` 照常报算法算出的 PWM → 上车前可干看
- 接口文档：`firmware/文档/驱动接口说明.md`（索引 + 调用骨架 + 未完成清单 + 自检命令表）
- 组员双入口：VS Code（打开 `firmware/`，PlatformIO 按钮）／仓库根 `工具箱.bat`（菜单）
- **板载快照（黑匣子）**：`app/app_log.{c,h}` — RAM 记录 + 停车写内部 Flash（掉电不丢）+ 上电自动恢复；
  跑车时插不了串口，靠它事后读（`DUMP` → `tools/snapshot.py`）。帧 8 字节（含左右轮真实增量 `dL/dR` 与陀螺仪偏航率 `gz`）
  ⇒ 可用 `tools/track.py` 做**航位推算重建实际轨迹（= 轨道形状）**
- **固件体积红线**：Flash 最后 **10KB**（`0x0800D800`）归快照 ⇒ **固件必须 < 54KB**；
  `firmware/check_size.py` 挂在编译后自动拦截（超限报错，不再靠人看百分比）
- **不许用 `%f`/`%g` 打印浮点**（会拉进 `_dtoa_r` + 双精度软浮点库，实测 ~9KB）⇒ 用 `Bsp_FmtFix()` 定点输出
