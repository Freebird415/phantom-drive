> 这里**任何人都可以更新**（与 `docs/` 的规范文件不同）。
> 但它们有严格分工，别互相串味——**写之前先看 `docs/文档维护.md`**。

## 常见写错的地方

- ❌ 把"试错过程"写进 `开发记录.md`（那是 `经验与踩坑.md` 的活）；
- ❌ 把"计划"抄进 `实际进度.md`（计划归 `开发记录.md`，两处对不上最麻烦）；
- ❌ 把没复现的推断写成事实（见 `docs/文档维护.md` §0 铁律）；
- ❌ 改完不更新文件头的"最后更新：日期 · 版本"。

> 进度类的一句话交接也可以走 `留言板.md`（仓库根 / 各工作区），但**流水账不进留言板**。
