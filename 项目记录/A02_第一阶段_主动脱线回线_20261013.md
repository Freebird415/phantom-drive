## 2. 实际实现

`A01 → DECEL(9) → OUT(10) → FWD(11) → RETURN(12) → RECOVER(6) → A01`；未捕获或短暂丢线可以进入 `SEARCH(13)`，预算耗尽进入锁存 `FAULT(7)`。

括号是内部阶段，不是新增遥测状态码。外部仍使用原有 `state=2/3`，具体阶段通过 `$E` 的 `A02 TEST p… c… dir…` 追踪。

1. 只在明确启用第一阶段、A02驱动许可开启、A01真实在线且处于正常循迹时累计触发条件。计数来自 TIM4左/TIM3右的TI12原始四倍频增量，两轮前进符号应为正；16位回绕以有符号增量处理。`(dL+dR)/2` 是平均轮侧进度，不是可靠车体位移。
2. 触发前窄线、中心位和误差必须稳定250ms；坏方向/跳变不会累计触发进度。触发2000平均计数后，先消费单次标志，再核实MPU有效新鲜、已静置标偏和方向合法。停止/重新发车/切换AVOID不重新武装；只有重新上电初始化允许下一次。
3. DECEL从A01本拍左右PWM接续，逐步降共同PWM和差速；低速及输出范围稳定150ms后才能OUT。OUT/FWD/RETURN全部按**计数进度**转换，不靠计时结束转向。时间仅用于故障截止。
4. 左右使用同一套数值，只有脱线方向和反摆方向变号。始终正向命令，不命令倒车或单轮停转原地找线。输出为有界差速，不计算固定转角/准确横移。
5. OUT/FWD必须观察到连续60ms全白，证明灰度确实暂时离开黑线；否则FWD结束即停。RETURN至少走150计数，才接受1～4路**连续**黑位作为候选；原先起始黑线不会直接成功交接。
6. 候选先低速局部P/D居中。全白/宽黑/离散黑点不算成功；短失线先低速续搜，超过150ms或原有名义25mm后进入SEARCH。搜索预算首次启动后**包含后续所有重新捕获/居中时间及行程，不会反复重置**。
7. 连续350ms满足居中和交接条件才交回A01。保留现有 `Trace_FinReset()`：清旧I/D/舵量及共同PWM起步量，但不清精停武装、里程与停止距离。第一阶段成功事件刻意写成 **`A02 TEST local line stable; A01`**，不冒称已识别原线路。
8. 新路径不调用旧导航的yaw积分、曲率外推、坐标预测/虚拟障碍外廓规划。旧v5路径及外廓保护仍保留于默认分支；第一阶段不是通过放宽旧保护“通过绕障测试”，而是只运行**无障碍标定动作**。

### 反馈监测与控制分离

第一阶段不以陀螺积分驱动路线，也不在局部灰度P/D中加入陀螺控制项；但保守地保留反馈健康门槛和转向活动诊断：

- 有效标记/序号、最大80ms缓存年龄、停机16个不同新样本的零偏要求不变。
- 轮侧证据只比较符号/明显活动，不将未经标定轮距和计数比例算成角速度真值。
- 第一阶段PWM差速较小，因此诊断启动条件从旧分支的 `|L-R|≥8` 单独改为本模式 `≥4`；原分支仍为8。100ms窗口、3个连续异常窗口、计数差至少12且至少占轮侧绝对增量25%、近零3°/s/整窗口原始零/反号条件保持。
- 新增健康安全门：测得角速度绝对值连续100ms超过60°/s则停车；不是转向目标角速度，也不是单帧噪声即刹停。
- 写电机之前再次查新鲜度；本拍 `Log_Note` 检出I2C失败会**同拍刹停**。故障先刹车后写日志，不靠蓝牙消息完成刹车。
- 维持30mm正读数极近保护；−1/−2不能证明清障或安全空间。不要把文档的30cm笔误带入代码。
- 双轮均需周期性出现正进度；单轮停转也触发500ms无进度保护。显著负增量/超大跳变、控制延迟>80ms、各阶段/总计数/总时限均停车。

可行性三问已限定：车和人明天在场地，电脑留在台面；烧录只在**台面、轮子架空、停止并供电确认**后进行，须另获用户明确授权；跑道不插ST-Link/TTL、不拖电脑，优先无线接收日志。现场日志如果不可靠，停止升级测试，不要求人在运动中插线。必须插线读取快照时，先停车再拿回台面。

你只需：测试前打开「蓝牙日志.bat」，确认有**新帧持续到达**而不是只看“已连接”；上电静置至少2秒，健康事件 `AV G v1 s0 b1`（a≤80ms）正常后才发车。长按PA12约1秒发车，按键会开启A01/A02许可、BLE和快照；自动动作到进度才触发，不需要电脑发送运动命令。每次重新测试必须先停车并保存日志，再重新上电静置，不能靠反复长按重新触发。

每次记录：固件hash/en/dir和全部调参值；`$T`时间、8路黑位、err、左右PWM、state、dl/dr、gz；`$U`左右mm；`$E`阶段p/c/dir、健康v/s/b/a/r/f、故障88和交接4。CSV的gz已经是°/s，不再乘2；健康r是原始LSB。不同类型时间尺不能直接相减，使用电脑接收时间和同类型事件时间。BLE的dl/dr是抽样增量，**缺帧时不能简单求和当精确里程**；精确触发进度以E事件的车载c为准。

板载快照仅1200帧约12秒，写满即停止记录而非循环覆写，且长按发车不会自动清上次帧；不能保证20秒动作及回线后1秒全有100Hz数据。以完整BLE会话为主；若要清旧快照，先在台面保存/导出旧数据，另行确认再清，不能在跑道靠电脑控制。快照写满不等于电机停车。

紧急停止：若动作明显危险，使用旁边可及的车载总开关立即断电，不等蓝牙或1秒长按；安全情况下用长按停车保存快照，听三短声。不捏旋转轮子、不用手当障碍、不用拔线制造运行故障。任何FAULT后不得继续落地，先查日志；不关闭保护继续试。

### 第一轮：台面架空，确认方向与失配停车

你只需：在电脑旁把车稳固架空，灰度下放已有黑线样片保持1～2路中心黑，手远离车轮；确认拟烧录的左右开启版后，另行授权烧录。烧录线在台面完成，随后按上述车载按钮启动。

- 观察：发车前不自启；两轮向前；左右增量为正；到2000平均计数出现p9减速、p10脱线；右版应L>R，左版应L<R；两轮PWM不突增/不反号。
- 记录：共通字段，尤其p9→p10、PWM差、轮侧增量和原始r/健康年龄，以及第一条FAULT。
- **正常限制**：车身架空不旋转，但两轮差速转动，MPU真零与轮侧转动相矛盾；满足连续证据后应报`gyro/wheel mismatch`并刹停。这是本轮预期的安全验证，不能为了走完RETURN而关掉监测。若低PWM轮侧差不足证据门槛，保持黑线样片也应最终报“未脱线”或阶段超时，仍不能声称完整架空回线通过。
- 必须停：轮子反向、编码器反号、松动/抖动、单轮不动、异常后仍持续差速、灰度失效或健康异常却继续转。方向不对先查符号/安装，不单方改共享驱动。
- 可调整：只在停机审核后改测试方向；不调A01、不关闭30mm/反馈保护，不做物理堵转。完整阶段转换已离线验证，架空不能验收路径。
- 成功：两轮正向、左右差速方向正确、减速平顺；失配或动作限界能实际刹停，并且健康恢复也不自行重启。

### 第二轮：无障碍、单一直线黑线、低速完整流程

你只需：先停车并把车从台面放到开阔的**测试直线**，灰度正常压中心线；脱线侧和前方留足空白区域，不用相邻赛段/岔路/宽黑标识，不摆真实障碍物，不靠布边/桌边。电脑只无线接收。先试一个已核对方向，重上电静置，再长按发车。

- 观察：A01正常后到车载进度才减速；向指定侧脱离；全白短时间但受限；正向短走；相反回摆；捕线后明显低速居中；事件4后稳定循迹至少1秒。实际看到同一根唯一黑线才能确认“原线”。
- 记录：标记第一次全白、首次回线黑位、p12/p6、交接事件和后1秒；记录现场视频/人眼实际左右方向和车轮有无反转，PWM正不等于机械必然正向。
- 必须停：超过预期范围仍朝一侧转、接近空场边界、快速偏航、未出现FWD/RETURN、全白无止境、任一故障、误捕别的线、回线后甩尾；不用等待保护才停。日志掉帧严重时不把结果计入验收。
- 可调整：首轮不现场增速；停车后依据阶段证据调整脱线计数或差速一项，幅度≤10%，重新构建/检查体积/获烧录许可。没有脱线就根据反馈调整OUT；过度偏离就优先减少OUT或舵量，不靠延长无界搜索。
- 成功：完整阶段顺序、确有全白再捕获同一根黑线、350ms稳定交接、回线后1秒\|err\|≤1、全程不倒车、无FAULT；只算该方向一次，绝不称完整避障完成。

### 第三轮：左右重复性与小步标定

你只需：在相同直线、同一灰度高度/光照和足够电量下分别跑左/右；每轮停车、导出日志、重新上电静置。切换方向需要在台面重新配置并获授权烧录，不在运动中发命令。每轮记录固件hash；调参后之前次数不累计进新参数的连续成功数。

- 观察/记录：同第二轮，加左右动作计数、最大PWM差、停转现象、各阶段耗时、回线后1秒err及视频。左右对称先验证相同参数，不为单侧成功无依据放宽安全限制。
- 可以调：目标速度/OUT计数/短前进计数/RETURN计数/舵量每次只调一项且≤10%；PWM上限、350ms、30mm、健康/时限保护保持。若低PWM不能可靠前进，先停止并测最低可行前进命令，不直接高差速补偿；改变最大PWM/安全门槛需重新设计和验证。
- 必须停：任一方向连续失败2次、碰边/误线、反转、快速转向、健康失配、回线后误差越界或明显甩尾；回到上一已验证低风险配置，分析后再试，不继续攒次数。
- 达标：**同一最终配置，左10次连续成功、右10次连续成功**；每次完整流程、正确原线、交接后至少1秒\|err\|≤1、无倒车、无FAULT且日志/观察证据足够。当前该目标实车次数为0，尚未达到。

## 7. 风险与申请烧录状态

1. 计数到mm、轮距、PWM—速度/转向响应、驱动轮端灰度前置量都未精标；动作可能不足以脱线，也可能回摆不足。必须从直线单线、开阔空场标定，不直接上真实障碍。
2. 单灰度条不能证明另一条线是不是原线；本版本只能稳定捕获局部候选。岔路/相邻线/复杂曲率不在第一轮验收范围；无法排除误线则停止，不宣传通用回线能力。
3. MPU零反馈的硬件/安装真因仍未现场闭环。保留监测意味着若异常未修好，本模式会安全停而不是完成动作；不能拿健康事件的静止raw=0认定损坏，也不能拿gz8=0认定健康。
4. A02内部PWM平滑已验证。**A01交接仍继承v5复位后由1档逐拍起步**，例如9/9→1/1→2/2；这是共同减速，不是旧差速残留，但不满足跨控制器每拍≤1档的严格连续性。该限制应现场观察；如果必须消除此下降，需要A01维护人批准修改共享交接机制，本轮未越权改A01。
5. 5%PWM在地面是否能克服阻力未知；正PWM不证明无实际倒转/打滑。无进度保护故意保守，不能通过降低计数门槛关闭它。
6. 30mm超声保护受测量覆盖、近距盲区和更新影响，不等于可靠防碰撞。因此第一阶段必须无障碍，留人可及时断电的空场。
7. Flash仅324B余量、快照仅约12秒、无线会掉帧；都限制后续调试，不能默默挪保留区/扩RAM/宣称有全程完整采样。
