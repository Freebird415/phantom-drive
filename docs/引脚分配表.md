## 一、总原则

1. **一个引脚只做一件事**，不在同一脚上挂两个功能。
2. **硬功能优先锁死**：串口、SWD、PWM、编码器、I2C 这些受外设通道限制的先分配、不动。
3. **软功能可动**：蜂鸣器、按键、指示灯、预留脚只受布线影响，改前同步一句即可。
4. 高容错要求（每接口"座子 + 排针"双份、测试点、未用 IO 引出、烧录不拆车）见 `电气连接规范.md` §8。

### 1.1 引脚预算：**33 个可用**

| 引脚区 | 可用性 |
|---|---|
| PA0~PA15、PB0~PB15、PC13 | 可用（33 个） |
| **PC14 / PC15** | **不可用** —— 板上 32.768kHz 晶振占用（实物照片确认） |
| **PD0 / PD1** | **不可用** —— 板上 8MHz 晶振占用（固件用 HSI，不依赖它） |
| PA11 / PA12 | **只可作输出** —— 板载 USB；PA12 有 1.5k 上拉（R10），作输入恒读高 |

本表用满 33 个，**预留 4 路**（PB3、PB4、PB5、PA12）。

## 二、电源（不占信号 IO）

```
DC005/2P焊盘 → 总开关 → 3A 慢断保险丝 → P-MOS 反接保护 ─┬─→ TB6612 VM（大电流，不走排针）
                                                        └─→ MP1584 → 5V ─┬─→ 感为灰度/超声波/HC06/TB6612逻辑
                                                                          ├─→ 核心板 5V 脚
                                                                          └─→ 核心板 RT9193 → 3.3V（编码器/OLED/MPU6050）
```

| 项 | 要求 |
|---|---|
| 单电源 | 全车只有一块 12V 锂电池（规则硬要求） |
| 保险丝 | **3A 慢断**，可换座 |
| 反接保护 | P-MOS，不得省 |
| **5V / 3V3 二选一** | 核心板的 5V 脚与 3V3 脚**只能接一个**（本项目接 5V）；本板**不得**自行产生 3.3V |
| 电压检测 | 12V → 100k/10k 分压（100nF）→ **PB0** |
| 测试点 | 12V / 5V / 3.3V / GND 各 ≥1 |

> 3.3V 由核心板 RT9193 输出，**≤300mA** —— 负载核算见 `电气连接规范.md` §11 第 3 条。

## 四、外设与定时器占用

| 外设 | 用途 | 引脚 |
|---|---|---|
| USART1 | 遥测（车 → 电脑） | PA9 / PA10 |
| USART2 | 蓝牙调试通道 | PA2 / PA3 |
| TIM1 | **备用** | — |
| TIM2 | 编码器（左） | PA0 / PA1 |
| TIM3 | 编码器（右） | PA6 / PA7 |
| TIM4 | 电机 PWM ×2 | PB6 / PB7 |
| I2C1（重映射）| 灰度总线（5V 上拉）| PB8 / PB9 |
| I2C2 | OLED + MPU6050（3.3V 上拉）| PB10 / PB11 |
| ADC1_IN8 | 12V 电压检测 | PB0 |
| SysTick | 1ms 时基 | — |
| DWT->CYCCNT | 超声波回波微秒计时 | — |

> **软件配置要点（P02 落地按此写）**
> 1. 时钟：HSI 8MHz → PLL → 64MHz（不用 HSE）。
> 2. 关 JTAG 保 SWD：`__HAL_AFIO_REMAP_SWJ_NOJTAG()` → 释放 PA15 / PB3 / PB4；（**NRST 必须引到 SWD 排针**，否则跑飞只能拔板）
> 3. I2C1 重映射到 PB8/PB9：`__HAL_AFIO_REMAP_I2C1_ENABLE()` → 把 PB6/PB7 让给 TIM4 PWM。
> 4. 感为灰度 I2C 7bit 地址：默认 **0x4C**；AD1/AD0 都装跳线 = 0x4F。
> 5. `HAL_Init()` 开了 SysTick，**必须自己实现 `SysTick_Handler`**，否则灯不闪、串口无输出。

## 五、原理图设计要求（高容错清单）

详见 `hardware/原理图草案/电气连接规范.md` §4 / §8。核心几条：
1. 每个对外接口 = **带扣座子 + 并排 2.54 排针**双份；丝印印出引脚名。
2. **SWD 排针 1×5 含 NRST**；复位键与 BOOT0 跳线由核心板提供，本板不重复。
3. TB6612 的 AIN/BIN 各加 10k 下拉（复位期间防电机乱动）；STBY 保留跳线可硬件常使能。
4. 超声波 Echo 分压；两个 Trig 独立。
5. 编码器 A/B 串 100Ω + 并 1nF（与电机电流同排线，需抑制噪声）。
6. 两条 I2C 总线**绝不并联**（5V vs 3.3V 上拉）。
7. 大电流不走排针；12V/5V/3.3V/GND 各留测试点。

## 七、备用与扩展

### 7.1 "黑匣子"数据记录（待定，影响引脚）
比赛时正常走有线遥测（100Hz 到笔记本）；板载再存一份是掉电/断线保险。

| 方案 | 成本 | 容量 | 占引脚 | 说明 |
|---|---|---|---|---|
| **A. RAM 快照 + 停车后 dump**（推荐先用）| ¥0 | ~8 秒（20KB / 24B 每帧）| **不占** | 车停后一条 `DUMP` 命令经串口读出，不磨损 Flash |
| B. 内部 Flash 环形存档 | ¥0 | ~30KB | **不占** | 只能"停车后刷盘"（页擦除 20~40ms）|
| C. 外挂 SPI Flash（W25Q64）| ¥3–8 | 8MB ≈ 43 分钟 | 需 SPI2，**当前无空闲 IO** | 要先买、并走变更流程释放引脚 |

### 7.2 感为的并行/串行备份路径
感为的针 5~12（并行）与针 13/14（串行）已在 PCB 上引到排针但不接 MCU。若日后要切并行（拿更细的模拟量），需要 8 个空闲 IO —— 当前没有（可用 IO 已排满 33 个），属**变更事项**。

### 7.3 其它
- TIM1 空闲，可做蜂鸣器 PWM、精停计时或第二组 PWM。
