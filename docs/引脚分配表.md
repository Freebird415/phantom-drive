## 一、总原则

1. 一个引脚只做一件事；复用功能只在备注里说明，不实际叠用。
2. **硬功能先锁死**：串口、SWD、PWM、编码器、I2C —— 受外设通道限制的先分配。
3. **软功能可动**：蜂鸣器、按键、指示灯、预留脚只受布线影响，改前同步一句即可。
4. 高容错要求见 `电气连接规范.md` §8（每接口"座子 + 排针"双份、测试点、未用 IO 引出、烧录不拆车）。

### 1.1 引脚可用性

| 引脚区 | 状态 |
|---|---|
| PA0~PA15、PB0~PB15、PC13 | 可用（33 个，本表用满） |
| **PC14 / PC15** | **不可用** —— 板上 32.768kHz 晶振占用（实物照片确认） |
| **PD0 / PD1** | **不可用** —— 板上 8MHz 晶振占用（固件用 HSI） |
| **PB2** | **保留勿接** —— BOOT1，复位时被拉高会从 SRAM 启动（不是 Flash），造成"上电不跑固件"的假故障 |
| PA13 / PA14 | 锁死给 SWD |

> **JTAG**：固件执行 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` 关闭 JTAG、保留 SWD，从而释放 PA15 / PB3 / PB4 作预留。
> 代价是必须能"连接下复位"，所以 **NRST 必须引到 SWD 排针**（核心板自带的 4pin SWD 没有 NRST）。
> 注意：**核心功能不依赖关 JTAG** —— 右超声波 Echo 特意放在非 JTAG 的 PB5；关 JTAG 只是为了多出 3 路预留。

## 二、电源（不占信号 IO）

```
DC005/2P焊盘 → T3A 慢断保险丝 → AO4407A P-MOS 反接保护 → 总开关 ─┬─→ 12V_BUS → TB6612 VM（大电流，不走排针）
                                                                └─→ MP1584 → 5V_BUS ─┬─→ 感为灰度 33mA / 超声波×2 / 编码器×2
                                                                                     └─→ 核心板 5V 脚 → RT9193 → 3V3_LOGIC
                                                                                                     （OLED / MPU6050 / TB6612 VCC / I2C2 上拉）
```

| 项 | 要求 |
|---|---|
| 单电源 | 全车只有一块 12V 锂电池（规则硬要求） |
| 顺序 | 保险丝在最前（保护其后所有电路）→ 反接保护 → 总开关 |
| 保险丝 | **T3A 慢断，可换座**（预留值；整车落地后实测巡航/起步/原地转向电流再定值） |
| 反接保护 | **AO4407A（SO-8，30V P-MOS）**，栅极 100k 下拉到 GND；不用 IRF9540（体积大、导通电阻高），不优先 AO3401（Vgs 余量不足） |
| **5V / 3V3 二选一** | 核心板 `5V` 脚与 `3V3` 脚**只能接一个**（本项目接 5V）；本板**不得**自行产生 3.3V |
| 滤波 | 12V_BUS 对地 470~1000µF/25V + 0.1µF，可预留 TVS；MP1584 输入输出电容靠近模块 |
| 电压检测 | 12V_BUS → 100k/10k 分压（并联 100nF）→ **PA0 (ADC1_IN0)**；满电 12.6V → 1.15V |
| 测试点 | 12V_BUS / 5V_BUS / 3V3_LOGIC / GND 各 ≥1 |

> 3V3_LOGIC 由核心板 RT9193 输出，**≤300mA** —— 负载核算见 `电气连接规范.md` §11。

## 四、外设与定时器占用

| 外设 | 用途 | 引脚 |
|---|---|---|
| USART1 | 遥测（车 → 电脑，USB-TTL） | PA9 / PA10 |
| USART2 | BLE 蓝牙（仅调试） | PA2 / PA3 |
| TIM1 | 电机 PWM ×2（20kHz） | PA8 (CH1) / PA11 (CH4) |
| TIM2 | **空闲**（保持默认映射，不产生 remap，避免抢 PA2/PA3） | — |
| TIM3 | 右编码器 | PA6 / PA7 |
| TIM4 | 左编码器 | PB6 / PB7 |
| I2C1（重映射） | 灰度总线（**5V 上拉**） | PB8 / PB9 |
| I2C2 | OLED + MPU6050（**3.3V 上拉**） | PB10 / PB11 |
| ADC1_IN0 | 电池电压检测 | PA0 |
| SysTick | 1ms 时基 | — |
| DWT->CYCCNT | 超声波回波微秒计时 | — |

> **软件配置要点（P02 落地按此写）**
> 1. 时钟：HSI 8MHz → PLL → 64MHz（不用 HSE）。
> 2. `__HAL_AFIO_REMAP_SWJ_NOJTAG()` —— 关 JTAG 留 SWD，释放 PA15/PB3/PB4。
> 3. `__HAL_AFIO_REMAP_I2C1_ENABLE()` —— I2C1 移到 PB8/PB9，把 PB6/PB7 让给 TIM4。
> 4. **不要设置 TIM2 的任何 remap**（Full Remap 会把 PA2/PA3 复用成 TIM2_CH3/CH4，与 USART2 抢脚）。
> 5. 感为灰度 I2C 7bit 地址：默认 **0x4C**；AD1、AD0 都装跳线 = 0x4F。
> 6. `HAL_Init()` 已开 SysTick，**必须自己实现 `SysTick_Handler`**，否则灯不闪、串口无输出。

## 五、原理图设计要求（高容错清单）

详见 `hardware/电气设计/电气连接规范.md` §4 / §8。核心几条：
1. 每个对外接口 = **带扣座子 + 并排 2.54 排针**双份；丝印印出引脚名。
2. **SWD 排针 1×5 含 NRST**；复位键与 BOOT0 跳线由核心板提供，本板不重复。
3. TB6612 的 AIN1/AIN2/BIN1/BIN2/STBY 各加 **10k 下拉**（复位期间防电机乱动）。
4. 超声波 Echo 分压；两个 Trig 独立。
5. 编码器 C1/C2 串 100Ω、可选并 1nF（与电机电流同排线，抗噪）。
6. 两条 I2C 总线**绝不并联**（5V vs 3.3V 上拉）。
7. 大电流不走排针；四个电源域各留测试点。

## 七、备用与扩展

### 7.1 “黑匣子”数据记录（**已实现 2026-10-01**）
比赛时正常走有线遥测（100Hz 到笔记本）；板载再存一份，解决**跑车时插不了串口**的根本矛盾。
实际采用的是 **A+B 合并方案**：

| 层 | 实现 | 容量 | 占引脚 |
|---|---|---|---|
| RAM | `LOG_MAX_FRAMES` 帧 × 8B（跑车中只写 RAM，零阻塞）| 12.8KB ≈ 16 秒 | **不占** |
| 内部 Flash | 最后 10KB（`0x0800D800`）；**停车时自动把 RAM 写进去** ⇒ 掉电不丢 | ≤ RAM 容量 | **不占** |

- 帧内容：8 路灰度(1) + err×10(1) + pwm_l(1) + pwm_r(1) + state(1) + dL(1) + dR(1) + gz(1)
- 读出：`DUMP` 经串口吐出（**格式同 `$T`**）→ `tools/snapshot.py` 存 CSV 出图；`tools/track.py` 重建轨迹
- ⚠️ **代价**：固件不得压进 `0x0800D800` ⇒ **固件 < 54KB**（`firmware/check_size.py` 自动拦截）
- 未采用：C. 外挂 SPI Flash（W25Q64）—— 需 SPI2，而 33 脚已排满，要用得走变更流程

### 7.2 感为的并行/串行备份路径
感为的针 5~12（并行）与针 13/14（串行）已在 PCB 上引到排针但不接 MCU。若日后要切并行（拿更细的模拟量），需要 8 个空闲 IO —— 当前只有 3 路预留，属**变更事项**。
