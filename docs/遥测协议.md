# 遥测协议

> 固件 ⇄ 上位机（`tools/`）之间的数据约定。**改协议要两边同时改，且需双方确认。**
> 最后更新：2026-09-13 · v1.0

## 一、物理层

| 项 | 约定 |
|---|---|
| 接口 | USART1（PA9 = TX，PA10 = RX），接 USB-TTL |
| 参数 | 115200 8N1（数据量大了再升 460800；升之前两台机器都要改） |
| 速率 | `$T` 帧 100 Hz；`$P` 上电一次；`$E` 事件触发 |
| 方向 | 车 → 电脑：`$T` / `$P` / `$E`；电脑 → 车：命令文本行 |

## 二、帧格式

**通用规则**：ASCII、每帧一行、以 `\r\n` 结尾、逗号分隔、以 `$` + 类型字母开头。

### 2.1 `$T` 遥测帧（100 Hz）

```
$T,<ms>,<s0>,<s1>,<s2>,<s3>,<s4>,<s5>,<s6>,<s7>,<err>,<pwm_l>,<pwm_r>,<state>
```

| 字段 | 含义 | 类型/范围 |
|---|---|---|
| ms | 上电毫秒数 | 整数 |
| s0..s7 | 八路灰度二值化结果（0=白，1=黑） | 0/1 |
| err | 循迹偏差（传感器编号单位，0 = 正中） | 一位小数，约 −8.0~+8.0 |
| pwm_l / pwm_r | 左右轮 PWM 占空比 | 整数，−100~100（负=反转） |
| state | 状态机 | 0=待机 1=循迹 2=避障 3=回线 4=精停 |

### 2.2 `$P` 参数帧（上电 1 次；`SET` 成功后也发一次）

```
$P,<ms>,<kp>,<ki>,<kd>,<base_speed>
```

> 作用：参数快照。**在线调参不会进 git**，靠这一帧把"当时用的是哪套参数"记进日志。

### 2.3 `$E` 事件帧（事件发生时）

```
$E,<ms>,<code>,<note>
```

| code | 含义 | code | 含义 |
|---|---|---|---|
| 1 | 丢线 | 90 | PONG（应答测试） |
| 2 | 检测到障碍 | 91 | 参数已修改 |
| 3 | 开始绕行 | 98 | 演示事件 |
| 4 | 回到循迹线 | 99 | 未知命令 / 其他 |
| 5 | 通过赛段标识 | | |
| 6 | 到达终点 / 开始精停 | | |

`note`：不含空格的短标签（便于人眼扫日志）。

## 三、命令（电脑 → 车）

每行一条，`\r\n` 结尾：

| 命令 | 作用 | 回复 |
|---|---|---|
| `PING` | 连通性测试 | `$E,<ms>,90,PONG` |
| `GET` | 读当前参数 | `$P` 帧 |
| `SET <名字> <值>` | 改参数（如 `SET kp 1.35`） | `$P` 帧（改后的值） |

可调参数名：`kp` `ki` `kd` `base_speed`。

## 四、扩展规则

1. **新增字段只能加在行尾**——旧的解析脚本不会因此报错
2. **改字段顺序 / 删字段 = 破坏性变更**，必须双方确认（C2、C3 的代码都按本表写）
3. 上位机解析见 `tools/telemetry.py`，画图见 `tools/plot.py`
