# 技术约定

> 项目技术红线与开发约定。写代码、画板、接线、定接口前读本文件。用户指令优先。

## 1. 硬性约束（违反＝扣分或取消资格）

- 整车尺寸 ≤ 250×200×200mm（超标每轮 −10%）
- 只能一块车载电源（多电源 −10%）
- 车架必须自制：主结构自行设计 + 中心设备加工（3D 打印/激光切割）+ 留照片/视频证据；买成品一票否决
- 全自动运行，比赛中禁止遥控
- 避障：与障碍物任何接触即失败；撞开不计分；障碍物从车底穿过不算
- 终点精停：车尾投影不得超过终点线（20 分）
- 非避障导致的脱线期间，所经赛段不计分 → 绕障必须短、快、可控

## 2. 电气约定

- 单电源架构：12V 锂电池 → TB6612 直供电机；降压模块（MP1584 / 5V-3.3V）供 MCU 与外设
- 必须安装总开关与保险丝
- 成品连接规范：
  - 电池/大电流 → XT30 / XT60 / T 插
  - 电机动力线 → 焊接 或 XH2.54 / JST-VH
  - 信号线 → XH2.54 / PH2.0 带扣插口
  - 不拆装的连接 → 直接焊死
  - 杜邦线仅用于调试与 SWD 烧录口
- 《引脚分配表》（`docs/引脚分配表.md`）为布线唯一依据 —— **计划 9/28 冻结，实际已于 2026-09-23 提前冻结**（王政淋确认，v3.0 为正式版）；冻结后只加功能、不改分配，改动需李沛阳、王政淋双方确认
- PCB 点亮节点：**10/11**（延迟会吃掉算法调试窗口）—— **PCB 已于 9/30 到货**，逐模块验收在成车上做

## 3. 软件约定

- MCU：STM32F103C8T6（现有 3 块）
- **固件体积 < 48KB** —— Flash 最后 16KB（`0x0800C000`）被**板载快照**占用（跑车时插不了串口，靠它脱机记录）；见 `firmware/驱动接口说明.md`；
  `firmware/check_size.py` 已挂在编译后自动拦截（**实测 `firmware.bin` 47.3KB，余量仅 ~1.8KB**；RAM 也已用掉 16.4/20KB，加功能前先算容量）；开发链路 CubeMX + PlatformIO / arm-none-eabi-gcc；烧录 ST-Link（命令行）
- 遥测：串口输出传感器原始值 / PID 中间量 / 状态机状态 / 事件打点；ASCII 帧优先；Python 脚本落盘 CSV 并绘图
  - **有线遥测**（USART1 + `tools/run.py`）用于台面调试；**板载快照**（`app/app_log` + `tools/snapshot.py`）用于跑车时脱机记录（`DUMP` 吐出的格式与 `$T` 相同）
  - 快照帧含**左右轮真实增量** ⇒ 可用 `tools/track.py` 做航位推算重建实际轨迹
- 驱动接口 **10/14 冻结**；冻结后只加功能不改接口，需变更时群内确认
  - **接口索引（A01/A02 先读这份）**：`firmware/驱动接口说明.md`
  - 权威来源是各 `firmware/src/drv/drv_xxx.h` 的**头注释**，索引只负责汇总与指路
- **算法层代码缝**：A01 只写 `firmware/src/app/app_trace.c`、A02 只写 `app/app_avoid.c`，
  每人**一个文件**（等于他们以前的 `main.c`）；算法层**只调 `drv_*` 的函数**，不直接碰寄存器/外设
- **算法发车开关默认关**（`TRACE 0` / `AVOID 0` = 只算不发）—— 防烧录后车窜出去；
  要真发车必须先发 `TRACE 1`，且**开之前把轮子架空**
- **小白协作路径**：VS Code 打开 `firmware` 目录（装 PlatformIO IDE 插件，底部有编译/烧录按钮）
  ＋ 仓库根双击 `面板.bat`（菜单式一键实验/看日志）；`.vscode` 只共享 `tasks/settings/extensions.json`
- 算法与调试一体：A01、A02 作者亲自上车调参
- 每次上车测试留档：日志文件 + 一句话结论

## 4. 安全

- 电池固定牢靠、防短路、用原配充电器；充放电不过充过放
- 上电前检查极性与短路；测试现场随时可断电（总开关）
