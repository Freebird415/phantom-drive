# 技术约定

> 项目技术红线与开发约定。写代码、画板、接线、定接口前读本文件。用户指令优先。

## 1. 硬性约束（违反＝扣分或取消资格）

- 整车尺寸 ≤ 250×200×200mm（超标每轮 −10%）
- 只能一块车载电源（多电源 −10%）
- 车架必须自制：主结构自行设计 + 中心设备加工（3D 打印/激光切割）+ 留照片/视频证据；买成品一票否决
- 全自动运行，比赛中禁止遥控
- 避障：与障碍物任何接触即失败；撞开不计分；障碍物从车底穿过不算
- 终点精停：车尾投影不得超过终点线（20 分）
- 非避障导致的脱线期间，所经赛段不计分 → 绕障必须短、快、可控

## 2. 电气约定

- 单电源架构：12V 锂电池 → TB6612 直供电机；降压模块（MP1584 / 5V-3.3V）供 MCU 与外设
- 必须安装总开关与保险丝
- 成品连接规范：
  - 电池/大电流 → XT30 / XT60 / T 插
  - 电机动力线 → 焊接 或 XH2.54 / JST-VH
  - 信号线 → XH2.54 / PH2.0 带扣插口
  - 不拆装的连接 → 直接焊死
  - 杜邦线仅用于调试与 SWD 烧录口
- 《引脚分配表》为布线唯一依据，第 3 周末冻结；冻结后改动需李沛阳、王政淋双方确认
- PCB 止损线：第 6 周未点亮 → 回退洞洞板方案，不占关键路径

## 3. 软件约定

- MCU：STM32F103C8T6（现有 3 块）；开发链路 CubeMX + PlatformIO / arm-none-eabi-gcc；烧录 ST-Link（命令行）
- 遥测：串口输出传感器原始值 / PID 中间量 / 状态机状态 / 事件打点；ASCII 帧优先；Python 脚本落盘 CSV 并绘图
- 驱动接口第 5 周末冻结；冻结后只加功能不改接口，需变更时群内确认
- 算法与调试一体：A01、A02 作者亲自上车调参
- 每次上车测试留档：日志文件 + 一句话结论

## 4. 安全

- 电池固定牢靠、防短路、用原配充电器；充放电不过充过放
- 上电前检查极性与短路；测试现场随时可断电（总开关）
