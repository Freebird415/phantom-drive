# 计划和任务 —— "谁 · 什么时候 · 交什么"

> 对外分发的简版任务清单；**与 `项目记录/开发记录.md` 同步，冲突时以《开发记录》为准**。

| 文件 | 说明 |
|---|---|
| `任务清单.md` | **唯一分发件**：已完成标 ✅、不删任务（PDF 已于 2026-10-12 停用/删除）|
| `生成任务清单.py` | 生成器：改动分工、节点、状态后重跑 |

## 什么时候重跑

改了**分工 / 节点 / 交接时间 / 任务状态**之后：

```bash
python 生成任务清单.py --build
```

只刷新 `任务清单.md`（另有 `任务清单.tex` 中间产物）；**PDF 已停用**。
只改错别字、不改数据的，重跑一次也无妨（幂等）。

> ⚠️ 别手改 `任务清单.md` / PDF：下次生成会被覆盖。要改就改 `生成任务清单.py` 里的数据源，或改《开发记录》后再生成。
