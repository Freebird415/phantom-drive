# 提交操作

**双击对应脚本即可，不需要敲任何命令。**

| 脚本 | 用途 | 什么时候用 |
|---|---|---|
| `更新到最新.bat` | 只拉取最新文件，不提交 | 开工前、想看看别人的更新 |
| `提交更改.bat` | 拉取 → 显示改动 → 填写说明 → 提交 → 上传（一条龙） | 做完一件事要上交时 |

> 脚本使用 GBK 编码（中文 Windows 双击即用）；在 GitHub 网页上直接查看可能显示乱码，属正常现象。

## 使用前提

1. 已经把仓库**完整 clone** 到电脑上（不能只复制一部分文件夹）
2. 已安装 Git 并配置过身份（见《说明书.md》第 1 节）
3. 第一次运行会弹浏览器要求登录 GitHub——登录一次以后就不用了

## 出错了怎么办

脚本会给出中文提示；搞不定就把**整个窗口截图**发到群里，不要自己乱敲命令。
