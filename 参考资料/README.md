# 参考资料 —— 课程与项目原始资料

| 子目录 | 装什么 | 规则 |
|---|---|---|
| `原文件/` | 课程材料与成员提供的原件：实训 PPT、比赛规则与评分标准 PDF（附件 1/2/3）、聊天记录总结、旧车/电池/元件照片 | **只读**：不修改、不删除；新收到的原件也放这里 |
| `原文件/STM32开发板照片/` | 核心板实物照（正面 1~4 + 背面）；**引脚可用性判断依据**（8MHz 晶振占 PD0/PD1、32.768kHz 晶振占 PC14/PC15、PA12 上有 1.5k 上拉）| 只读 |
| `原文件/灰度传感器照片/` | 感为 / 亚博两套八路灰度的**实物丝印针序图** | 只读；针序以实物为准 |
| `原文件/电机插头照片/` | JST-XH 6P 板端座 + 电机端插头（电机自带 6 芯线）| 只读 |
| `原文件/手册/` | 厂商手册：感为八路灰度数据手册（PDF）、亚博八路灰度教程与 STM32 读取页（HTML）| 只读；**器件参数以手册为准** |
| `原文件/平衡小车原理图（可参考）/` | 旧车队平衡小车的嘉立创 EDA Pro 工程（`.epro2`，可直接导入嘉立创 EDA 查看）| 只读；仅作参考，**不照抄** |
| `临时解析文件/` | 从 PDF / 手册提取的 txt / 页面截图等中间产物 | **可随时再生**：临时产物一律放这里，或直接删除 |

## 要求

- 涉及**判罚与评分**的问题，一律先查 `原文件/` 原文，不凭印象下结论
- 涉及**器件参数**（电压、电流、地址、时序）的问题，一律先查 `原文件/手册/`，不凭印象下结论
- 本文件夹只读使用，不在这里放工作文件
- 相关任务：全员（D02 展示材料会引用这里的材料）
